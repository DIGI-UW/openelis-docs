PurposeControl which items appear in the OpenELIS navigation by turning menu nodes on or off.

Who does thisAdministrators. Access is set by user permissions and can be configured by your administrator.
Before you startDecide which menu items your site should show or hide.
WhereMain menu → Admin → Menu Configuration.

Global Menu Management shows the full navigation as a tree. Each node has a Side Nav Active checkbox that controls whether it appears in the menu, and Show Child Elements expands or collapses the tree.

Step 1 — Open the menu tree

  1. Open Main menu, then click Admin.

Click Admin

  1. Click Menu Configuration.

Menu Configuration

  1. Click Global Menu Management.

Global Menu Management

Use Show Child Elements to expand the tree and see every node grouped under its parent (Order, Storage, Reports, and so on).

Global Menu Management: the navigation tree with a Side Nav Active checkbox on each node.

Step 2 — Show or hide items and save

  1. Tick or untick Side Nav Active on each node to show or hide it in the navigation.
  2. Click Submit to apply.

Edit and save

Field reference

ControlNotes
Show Child ElementsExpands or collapses the tree so you can reach nested nodes.
Side Nav ActivePer-node checkbox; when unticked, the item is hidden from the side navigation.

Notes

  • Hiding a parent node hides its children as well.
  • Changes apply to the navigation after you Submit.
  • This page only toggles the visibility of existing menu entries. Adding a new menu entry requires a database migration.
