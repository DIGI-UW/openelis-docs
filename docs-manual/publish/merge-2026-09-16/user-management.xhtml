How-to · Administrators (user-account administration)

At a glance

PurposeCreate and maintain the user accounts that can log into OpenELIS, and set each user's roles and permissions.
You'll end up withAn active user account with the right global and lab-unit roles.
Who does thisAdministrators (a User Account Administrator or Global Administrator). Access is set by user permissions and can be configured by your administrator.
Before you startThe person's name, a login name, and which roles / lab units they need.
WhereMain menu → Admin → User Management.

User Management lists the system users and their account status. From here you add a user, modify or deactivate one, and assign the roles that control what each user can do.

Step 1 — Find a user

  1. Open Main menu → Admin.

Admin

  1. Click User Management.

User Management

  1. The list shows each user's first and last name, login name, password expiration date, and account flags (Account Locked, Account Disabled, Is Active, User Time Out). Filter with Search By User Names, By Lab Unit Roles, Only Active, or Only Administrator.

Search By User Names, By Lab Unit Roles, Only Active, or Only Administrator.

  1. Tick a row's Select checkbox to enable Modify or Deactivate.

The User Management list, with filters and the Modify, Deactivate, and Add actions.

Step 2 — Add a user

  1. Click Add.

Add user

  1. Enter the Login Name, a Password that meets the stated rules (at least 7 characters, including one of * $ # !), and Repeat Password.
  2. Enter First Name and Last Name, set the Password Expiration Date and User Time Out (minutes), and set Account Locked, Account Disabled, and Is Active.

The Add User form: account details at the top, the Roles section, and Copy Permissions below.

Step 3 — Assign roles and save

  1. Under Global Roles, tick any that apply (for example Global Administrator, Audit Trail, User Account Administrator, Analyser Import, Pathologist, Cytopathologist).

Global Roles

  1. Under Lab Unit Roles, click Add New Permission and choose all lab units or a specific unit, then the roles (Reception, Results, Validation, Reports).

Add New Permission

  1. Optionally use Copy Permissions From User to copy an existing user's roles: enter their user name and click Apply.
  2. Click Save.

Add permission and save

Field reference

Field / RoleNotes
Login Name / PasswordSign-in credentials; the password must meet the on-screen complexity rules.
Password Expiration DateWhen the password must be changed.
User Time Out (minutes)Idle timeout before the session ends.
Account Locked / Account Disabled / Is ActiveAccount-state flags.
Global RolesApplication-wide roles, for example Global Administrator (all admin functions), Audit Trail (all audit trail), User Account Administrator (user administration only).
Lab Unit RolesPer-unit (or all-unit) roles: Reception, Results, Validation, Reports.
Copy Permissions From UserCopies another user's role assignments to this account.

Notes

  • Users are deactivated, not deleted: select a row and use Deactivate to retire an account while preserving its history.
  • The exact roles available and what they unlock are configurable per deployment; use the on-screen role descriptions as the source of truth.
