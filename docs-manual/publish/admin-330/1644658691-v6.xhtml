At a glance

Purpose

Define a new specimen type so tests can be configured against it and samples collected for it.

You'll end up with

An active sample type, available when configuring tests and entering orders.

Who does this

Lab administrators. Access is set by user permissions and can be configured by your administrator.

Before you start

The specimen name, which domain it belongs to, and a short description for lab staff.

Where

Main menu → Admin Management → Test Catalogue Management → Sample Type Editor

Domain assignment. Sample types are a shared, cross-domain registry. A sample type is not Environmental or Vector on its own — it becomes part of those workflows only once the domain configuration assigns it. Until then it is generic, available to whichever domains it is assigned to.

panel_c1

An older screen, Manage Sample Types, is still present and being retired. It behaves differently over activation — see the note at the end of this page.

Open the Sample Type Editor

The list shows every sample type with its domain, status and the number of tests configured against it. The header reports the total and a breakdown by domain, and the list can be searched and filtered by domain.

The Sample Type Editor list.

Create the sample type

  1. Select Add Sample Type. The Add New Sample Type form opens on Basic Info.

The Add New Sample Type form. Create Sample Type stays unavailable until the required fields are filled in.

  1. Enter the Name. This must be unique. The field's guidance gives Serum and Whole Blood as examples.

  2. Choose the Sample Domain. Clinical, Environmental or Vector. This determines which workflow mode the sample type appears in. Clinical is selected by default.

  3. Set Active. Unlike lab units and panels, a sample type can be made active on the create form. Leave it Inactive if you are not ready for it to be used.

  4. Enter a Description. Required. Keep it short — the field is capped at 60 characters.

  5. Select Create Sample Type. The button stays disabled until Name, Sample Domain and Description are all filled in. The form reopens as an edit view with the sample type's name and its domain and status shown as chips.

  6. Re-enter the description if it matters. On create, the description is replaced by the sample type's name. Whatever you typed in step 5 is not kept. Retype it now and select Save.

  7. Add the WHONET specimen code, if your laboratory reports to WHONET. This field appears only after the sample type exists. It is written to the WHONET SPECIMEN_TYPE field and takes at most five characters.

The sample type after creation, showing the WHONET specimen code field that is not on the create form.

Link tests to the sample type

Open the Associated Tests section. It lists every test linked to this sample type, with its Status and per-row actions.

  • Add test searches the catalog for a test to link.

  • Filter by sample type narrows the catalog search by another specimen type, which helps when a test already exists for a similar specimen.

  • Row actions remove an existing link.

The same link can be managed from the other side — a test's Sample types field on its Basic Info in the Test Catalogue Editor. Both edit the same relationship, so a test linked here appears there and vice versa.

Position it in the order-entry menu

Open the Display Order section. This positions the sample type in the Sample Type menu that reception sees at order entry.

Type a position or use the arrows, then Save. The section lists every sample type in its current order with a number, name and status, and marks the one you are editing as This sample type.

panel_c1

Saving renumbers every sample type, not just this one. The on-screen guidance says so directly. Expect the whole list to shift, and check the result rather than assuming only your entry moved.

Inactive sample types still occupy a position in this list. They simply do not appear at order entry.

Record disposal guidance

Open the Disposal section and enter Disposal instructions. This is a single free-text field.

It is reference guidance only. The screen is explicit that the authoritative, structured handling lives elsewhere — on each test's Sample Storage section and in the specimen disposal workflow. Use this field for a note to lab staff, not as the controlling record.

Configure the rest

The remaining sections are Terminology and Localization. Neither is documented yet.

Tips

  • The description you type on the create form is discarded and replaced by the name. Set the real description after creating the sample type.

  • Descriptions are capped at 60 characters.

  • The WHONET specimen code is not on the create form. Create the sample type first, then add it.

  • Saving Display Order renumbers every sample type, not only the one you changed.

  • Disposal instructions here are guidance, not the authoritative handling record.

  • Existing sample types may already carry test counts. Check the Tests column before deactivating one.

  • Because the registry is shared, this screen manages clinical, environmental and vector sample types alike. What makes one appear in a given domain is the domain assignment, not this screen alone.

How this differs from the legacy screen

On the older Manage Sample Types screen, a new sample type stays inactive until at least one test is assigned to it. Here, Active is set on the create form and a sample type can be saved as Active with no tests assigned. If you move between the two screens, expect that difference.
