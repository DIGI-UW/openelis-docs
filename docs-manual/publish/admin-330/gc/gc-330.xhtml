At a glance

Purpose

Look up what each General Configuration setting controls, and what it is set to.

You'll end up with

An understanding of which behaviours at your site are configuration-driven.

Who does this

Administrators, usually with technical support. Access is set by user permissions and can be configured by your administrator.

Before you start

Nothing. Read before changing anything — several of these settings change what other staff see on screen.

Where

Main menu → Admin → General Configurations

Read this first

These settings change what other pages in this manual describe. A how-to page shows one configuration's version of a screen. If a field described in a task page is missing at your site, or a field appears that no page mentions, the cause is usually a setting on this page rather than an error.

The settings most likely to cause that confusion are flagged Changes the UI below.

Every screen here works the same way: select a row, click Modify, change the value, save. Values are shown as they were found on the reference instance; yours will differ.
