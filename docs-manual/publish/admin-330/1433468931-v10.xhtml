Part of: Test Catalog Management — workflow overview

How-to · Lab administrators

At a glance

Purpose

Create or edit a label preset — a reusable barcode label definition (size, barcode type, scope, quantities) — and set the one site-wide barcode choice: where pre-printed label numbers come from.

You'll end up with

A label preset available for printing and for use by the test catalog.

Who does this

Lab administrators. Access is set by user permissions and can be configured by your administrator.

Before you start

—

Where

Main menu → Admin → Label Presets.

panel_c1

This page replaces the old Barcode Configuration screen. Barcode label settings used to live on a separate Barcode Configuration page with global Number / Elements / Dimensions sections. Those settings are now defined per preset here, with one exception that stays laboratory-wide: where pre-printed label numbers come from, which sits in the Site-wide Barcode Settings card above the list (see below). The Barcode Configuration tile on the Admin dashboard still exists but opens this page.

A label preset defines a printable barcode label: its dimensions, barcode type, the scope it applies to (an Order label vs a per-Sample label), and default/maximum quantities. OpenELIS ships five System presets — Order Label, Specimen Label, Block Label, Slide Label, Freezer Label (all CODE_128, 25 × 76 mm) — and you can add your own.

  1. Open Main menu → Admin → Label Presets. The list shows each preset's Name, Barcode Type, Dimensions, Scope, and Status. Use Search presets… to filter.

Label presets

  1. Click Add Preset, or use the row Actions (⋮) menu → Edit to change an existing one. The same menu offers Duplicate.

Add preset

  1. Under Basic Info, enter a Preset Name and set Active.

  2. Under Dimensions (mm), set Height and Width.

  3. Under Barcode Settings, choose the Barcode Type — CODE_128, QR, or DATAMATRIX.

  4. Under Print Scope & Quantities, tick Order and/or Sample. Each scope you tick reveals its own pair of quantity fields — Default per Order and Max per Order for the Order scope, and the equivalent per-Sample pair for the Sample scope. The maximum is the limit beyond which no further labels can be printed.

  5. Under Content fields, choose what the label prints above its barcode. Lab Number is always first and required and cannot be moved or removed. Use Add a field to pick from the fifteen other fields (patient name, ID, date of birth and sex, site ID, collection date and time, collected by, tests, specimen type, block, slide, stain, case number, storage location, expiry date), the arrow buttons to change the order, Required to make a field mandatory, and the bin button to remove one. A hint appears when the selected fields are unlikely to fit the preset's height (Lab Number is not counted, because it prints as the barcode's own text); you can still save. These fields decide what every label printout shows, including the Print Bar Code Labels page.

  6. Click Save.

Note: the five System presets are built in. New presets you create appear in the same list and can be edited or deactivated from the row Actions (⋮) menu. The System presets' content fields start as the retired Barcode Configuration screen printed them: the Order Label carries patient name, date of birth, ID and site; the Specimen Label adds sex, collection date and time, collected by and tests; the Slide, Block and Freezer labels carry their pathology and storage fields. A site that had switched any of those elements off on the old screen keeps them off.

Site-wide barcode settings

Above the preset list sits the one barcode setting that is not per preset: the Site-wide Barcode Settings card, tagged Applies laboratory-wide. It decides where the numbers on pre-printed labels (Order → Print Bar Code Labels → Pre-Print Barcodes) come from:

  • The same format and number pool as order entry — pre-printed labels take the next numbers of the ordinary lab number series.

  • A separate pre-printed series with a Prefix of exactly 4 letters or digits — pre-printed labels are numbered prefix, two-digit year, sequence number, and order entry accepts those numbers as lab numbers while this choice is active, so a pre-printed label can be scanned at order entry and attached to a new order.

  1. Choose one of the two options. The Prefix field is enabled only for the separate series; a prefix that is not exactly 4 letters or digits is refused before anything is saved.

  2. Click Save settings. The page confirms the save, and the stored choice is shown whenever the page is opened.

Note: a pre-printed label exists before any order, so patient details stay blank on it until its number is attached to an order. Switching back to the order-entry pool keeps the prefix in place for later.

Tips

  • The quantity field labels follow the scope, so they read "per Order" or "per Sample" depending on which box is ticked. If you see only one pair, only one scope is selected.

  • Deactivate a preset rather than deleting it, so existing history stays readable.

Related: the Test Catalog editor's Labels section lets a test suggest one of these presets at order entry. Barcode label printing during order entry is covered in the order entry pages.
