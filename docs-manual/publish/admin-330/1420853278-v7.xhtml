At a glance

Purpose

Create and manage sample types (specimen and organism types) from the legacy Manage Sample Types screen, assign tests to them, and set their display order.

Who does this

Administrators. Access is set by user permissions.

Where

Main menu → Admin → Test Management → Manage Sample Types.

Scope

This is a shared, cross-domain registry. A sample type defined here is generic until domain work assigns it to a domain — it only appears in Environmental or Vector order entry once it has been set to that domain.

Domain assignment. Sample types are not Environmental or Vector on their own. A sample type becomes part of the Environmental or Vector workflow only after the domain configuration assigns it to that domain. Until then it is a generic sample type available to whichever domains it is assigned to.

Manage sample types

The page offers three actions: Create New Sample Type, Set Sample Type Order, and Test Assignment.

To add a sample type, choose Create New Sample Type, enter the English and French names, and continue.

Use Test Assignment to assign at least one test to the sample type. A new sample type stays inactive until at least one test is assigned to it. Use Set Sample Type Order to position it in the lists where it appears.

Manage Sample Types, with its create, ordering, and test-assignment actions.

  • Because the registry is shared, the same screen manages clinical, environmental, and vector sample types — what makes a sample type appear in a given domain is the domain assignment, not this screen alone.

  • A sample type with no tests assigned remains inactive and will not appear for ordering.

How this differs from the Sample Type Editor

On this screen a new sample type stays inactive until a test is assigned to it. In the Sample Type Editor, Active is set on the create form and a sample type can be saved as Active with no tests assigned. If you are moving between the two screens, expect that difference.
