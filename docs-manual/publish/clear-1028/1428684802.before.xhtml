OpenELIS 3.3.0. In 3.3.0 clinical orders no longer use this stage: their samples are labelled and stored in Prepare samples for a clinical order. This page covers environmental and vector orders. Sites on earlier releases can use Label & store samples (before 3.3.0).

How-to · Reception and laboratory staff

At a glance

Purpose

Print the order and sample labels for an environmental or vector order, and either give each sample a storage location or record that it will be processed straight away.

You'll end up with

Labels for the order and each sample, storage assigned or skipped for every sample, and the order moved on to Sample check.

Who does this

Whoever labels and racks samples at your site. Access is set by user permissions and can be configured by your administrator.

Before you start

An environmental or vector order saved at Enter Order, a label printer, and, if you store samples, storage locations set up under Main menu → Storage.

Where

Main menu → Order → Add Environmental Order → Label & Store (or Add Vector Order → Label & Store). Save & Next on Enter Order brings you here.

Step 1: Check you have the right order

  1. The progress bar shows Enter Order, Label & Store and Sample check, with the time Enter Order was done. Below it, the order banner gives the lab number, its status (Entered) and the samples with their test counts. To work on another order, scan or type its lab number into Scan barcode or enter lab number.

Step 2: Print the labels

  1. Print Labels lists an Order Label (the lab number and sampling site, barcode the lab number) and a Sample Label for each sample (sample type, sampling site and collection date, barcode the lab number with a suffix such as .1).

    Label & Store for an environmental order from the Laloki River raw water intake: one order label and one sample label.

  2. Set the Quantity on each row, then select Print Label on a row or Print All Labels below the table.

Step 3: Store the samples, or skip storage

  1. Assign Storage Location names any sample that has no location yet. For each sample, either search for a location in Search for a storage location (two or more characters), or pick it level by level: Room, Device, Shelf, Rack, Box and an optional Position, with Condition Notes if needed.

  2. If the samples go straight to the bench, tick Skip storage for unassigned samples. A blue note confirms Storage skipped and that the samples will be processed immediately.

    Storage skipped for the one sample on the order.

Step 4: Save and go on to Sample check

  1. Select Save & Next. Label & Store is marked Done and the Sample check opens for the same order. Save keeps your choices and stays on the page; Back returns to Enter Order.

Refer out

Below storage, Refer Out / Subcontract lists each sample with its Sample ID, Sample Type, Tests, Referring Lab and Subcontract Status (In-house by default), with a Refer Out action for samples tested elsewhere. Referral was not exercised for this page.

Tips

  • Label sizes and barcode formats come from the presets your administrator keeps in Manage label presets.

  • If no storage locations are set up, the search and the Room list are empty; skip storage instead.

  • Known issue (3.3.0-SNAPSHOT): the Main menu still calls the next stage QA Review, while the progress bar and breadcrumb call it Sample check.
