Part of: Environmental Surveillance — workflow overview

How-to · Validator · Environmental

At a glance

Purpose

Review and release entered results so they are final.

You'll end up with

Validated, released results that leave the validation queue.

Who does this

Validator. Access is set by user permissions and can be configured by your administrator.

Before you start

Results have been entered on the order.

Where

Main menu → Validation → Routine (select the test unit).

Steps

  1. Open Validation

Click validation

  1. Select the lab unit. Alternatively, search by lab number or date rage

Select lab unit

  1. Expand the results accordion

Expand results

  1. Enter validation notes. Then, click on Validate & Release button.

Validate & release

The result is released and leaves the queue.

Note: if electronic signatures are enabled (Admin → General Configuration → Site Configuration), Save prompts for your e-signature.
