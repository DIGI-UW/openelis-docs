Part of: Environmental Surveillance — workflow overview

How-to · Analyst · Environmental

At a glance

Purpose

Record numeric results for a submitted environmental order and read the automatic PASS/FAIL compliance verdict.

You'll end up with

Saved results, each scored Status — Per Regulation against the standard.

Who does this

Analyst. Access is set by user permissions and can be configured by your administrator.

Before you start

A submitted environmental order; the test's reference limits configured in the standard.

Where

Main menu → Results (select the test unit).

Steps

  1. Open Results and choose the test unit (e.g. Water Quality). Submitted order rows load.

Results navigation

  1. Select test unit (water).

Select test unit

  1. Enter the numeric result (e.g. pH = 7)

Enter result

  1. Click Save.

Save

  1. Reload — the Status — Per Regulation column shows PASS (green) / FAIL (red) with the standard name. The U (k=2) column shows expanded uncertainty where configured.

  2. If a result is entered after the SOP max holding time, the result’s Notes carry an internal warning that the holding time was exceeded.

Note: the compliance evaluation is numeric-only and server-computed — it appears after Save + reload, not as you type. This build may show two “Water Quality” units; pick the one carrying your tests.
