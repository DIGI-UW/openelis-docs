How-to · Reception staff

At a glance

Purpose

Find an existing patient to view or edit their record, or start registering a new one.

You'll end up with

The right patient record open for review or editing.

Who does this

Reception staff. Access is set by user permissions and can be configured by your administrator.

Before you start

An identifier, a previous lab number or a name for the patient you are looking for.

Where

Main menu → Patient → Add/Edit Patient

The Add Or Modify Patient page is where you look up patients. Search by identifier or name, select a result to view or edit the record, or start a new patient record. Identifier labels can be set by your site; the figures show the test server's labels.

Step 1: Search for a patient

  1. Open Main menu → Patient → Add/Edit Patient.

Add edit patient

  1. The page opens on Search for Patient. Enter any of Patient Id, Previous Lab Number, Last Name, First Name, Date of Birth or Sex, and click Search. Clear empties the fields. External Search queries an external patient source when one is configured; it was unavailable on the test server.

Searching by last name finds one patient.

The results list shows Last Name, First Name, Sex, Date of Birth, the patient identifier, National ID and Data Source Name (OpenElis for records held in OpenELIS).

Search results

Step 2: Open and edit a record

  1. Select the patient with the button at the start of their row. Their record opens under Patient Information, read-only.

Select patient

  1. Turn on the Edit switch next to Patient Information. It reads Editing and the fields become editable. Make your changes and click Save at the bottom of the form.

The record with Editing on.

Step 3: Register someone new

If the patient is not found, click New Patient and complete the form. See Register a New Patient.
