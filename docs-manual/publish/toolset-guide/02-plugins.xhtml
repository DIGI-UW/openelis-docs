Goal of this page. Install the two OpenELIS plugins so that, when you ask for a manual page or a screenshot, Claude already knows how we do it and checks its own work. One-time setup, about 15 minutes; repeat when a new version comes out.

What a plugin is

A plugin is a package of house instructions (called skills) plus a few automatic safety checks. You never run a skill by hand: you describe what you want, and Claude loads the skill that matches. The safety checks run on their own and stop Claude before it does something we have agreed never to do (see "The safety checks" below).

Two related skills stay separate and are worth having: openelis-ui-vocabulary (keeps button and label names exactly as the software says them) and openelis-design (design and spec background). Ask Casey if you don't have them.

Install

  1. Download both plugin files (above) to your Mac.
  2. In the Claude app, upload each .plugin file where plugins are managed in settings. If you can't find it, ask Casey.
  3. Remove the old skills if you had them from the July setup: openelis-user-manual, openelis-screenshots, openelis-docs-freshness and triage-bench-sync. If both old and new are installed, Claude gets two sets of instructions and may follow the old one.

It also brings a page reviewer: a second Claude that reads a finished page cold, the way a fresh reviewer would, and lists what does not match the screenshots before the page is published.

The safety checks

These run automatically. When one stops Claude, Claude tells you why; that is the check working, not an error.

  • Publishing asks first. Before any script writes to Confluence, you are asked to approve it.
  • No em dashes. Our writing rule. A page or title containing one is refused until it is rewritten.
  • Safe page edits. Claude may only edit an existing Confluence page in the format that keeps its tables, comments and images intact.
  • Secrets stay secret. Claude is stopped from printing the publishing key or committing it to GitHub.
  • The bench gets updated. If Claude published or ran a check but did not update the triage bench, it is reminded before it stops.
