Goal of this page. Quick fixes for the problems you are most likely to hit, what the plugin's safety checks mean when they stop Claude, and the words used across this guide.

Common problems and fixes

What you seeMost likely causeWhat to do
Claude can't see GitHub or ConfluenceA connector is not connected or needs signing in againReconnect it in the app's connector settings (Part 1), then start a new chat.
Claude can't reach your MacThe Claude app is closed, the Mac is asleep, or the macOS permission was not givenOpen the app, wake the Mac, and check System Settings > Privacy & Security > Accessibility.
Claude follows old steps (for example, drafts a page in the review area first)An old skill is still installed next to the pluginRemove openelis-user-manual, openelis-screenshots, openelis-docs-freshness and triage-bench-sync (Part 2).
A capture shows the login page or a blank screenThe saved login expired, or the site was slowAsk Claude to log in to the harness again and retry. If it keeps happening, tell Casey.
Publishing fails with "not permitted to create attachments"The publishing key was made for Jira onlyAsk Casey for a new key with Confluence permissions. Retrying will not help.
The bench says the last freshness check is many days oldThe Saturday task did not run or could not reach the MacAsk Claude to "run the docs freshness check". Tell Casey if the Saturday run keeps missing.
Confluence returns a temporary error (for example 503)Atlassian was briefly unavailableWait a minute and ask Claude to try again.

When a safety check stops Claude

The plugin checks some actions before they happen. A stop is the check doing its job; Claude says which one and fixes the cause.

Message mentionsMeaningWhat happens next
"this writes to Confluence"A publishing script is about to runYou approve or decline. Approve only for the pages you asked for.
"em dash"The text has an em dash, which our writing rule does not allowClaude rewrites the sentence with a colon, comma or brackets and tries again.
"contentFormat adf"Claude tried to edit an existing page in a format that would damage its tables, comments or imagesClaude re-reads the page in the safe format and makes the edit that way.
"credentials" or "token"A command would have shown the publishing keyNothing is shown. If you need to confirm the key exists, Claude can check that without printing it.
"triage bench"Manual work happened but the bench was not updatedClaude syncs the bench, or says in one line why nothing changed.

Golden rules

  • Never paste passwords, tokens or patient data into a chat. Connectors and key files handle sign-in; Claude never needs a secret typed in.
  • Document only what the software does today. If you can't reproduce a step on the test site, don't publish it.
  • Every piece of manual work ends on the bench. If it isn't on the bench, nobody will see it.
  • When in doubt, ask Claude to explain what it is about to do, then ask Casey if you are still unsure.

Who to ask

For access, keys, plugin files and final publishing calls, Casey is the first stop. For "how do I phrase this?", ask Claude directly in the chat.

Glossary

TermPlain-language meaning
PluginA package of skills plus automatic safety checks. We use two: openelis-docs and openelis-qa.
SkillHouse instructions Claude loads by itself for one kind of task, such as writing a manual page.
ConnectorA secure link that lets Claude read and write in another system (Jira, Confluence, GitHub) or use your Mac. You approve each one.
ProjectThe claude.ai project "OpenELIS User Manual", which keeps the notes from every session.
Documentation triage benchThe live page listing what to fix next in the manual, with a ready prompt for each item. It replaced the Doc Freshness Tracker.
Freshness checkThe weekly run that opens every documented screen and checks the page still matches it, then checks the translations.
DriftThe screen changed since the page was written, so the page no longer matches.
ContractA page's list of screens and the labels it relies on; the freshness check uses it.
Work in progressA published page whose review is not finished; it carries a yellow note naming the review ticket.
Page reviewerA second Claude that reads a finished page cold and lists anything that does not match the screenshots.
Capture harnessThe project that signs in to the live software and takes the screenshots and videos (DIGI-UW/OpenELIS-QA).
Instance or siteA running copy of OpenELIS, such as testing.openelis-global.org.
Repository (repo)An online folder of project files on GitHub. Ours are DIGI-UW/openelis-docs and DIGI-UW/OpenELIS-QA.
Scheduled taskSomething Claude runs on a schedule, such as the Saturday freshness check.
