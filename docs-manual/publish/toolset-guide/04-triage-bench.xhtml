Goal of this page. Know where to start each time: the Documentation triage bench is the one list of what to fix next in the manual and its translations. It replaced the Doc Freshness Tracker in September 2026.

Open it: Documentation triage bench (sign in to claude.ai with the account from Part 1; ask Casey for access if it does not open).

How to work from it

  1. Pick the top item in Now (or one Casey assigned you).
  2. Copy its prompt into a new chat in the OpenELIS User Manual project.
  3. Let Claude do the work (Part 5 describes what happens).
  4. At the end Claude writes a short session note into the project and updates the bench: it closes the item, opens new items for anything left over, and stamps the time. If Claude seems to finish without doing that, ask it to "sync the triage bench".

Items are never deleted, only closed, so the bench also records what was done and when.

How the bench stays current

  • Every session that changes the manual ends with a bench sync. The plugin reminds Claude if it forgets.
  • Every Saturday a scheduled task runs the freshness check against testing.openelis-global.org and syncs the drift panel, the translation counts and any new items. It makes no changes to Confluence; it only reports.
  • Any time, you can ask Claude to "run the docs freshness check" (it takes up to 30 minutes plus a few minutes per language).

What the freshness check does

Every manual page has a short "contract": the screens it shows and the labels and buttons it relies on. The check opens each screen on the test site and confirms those labels are still there. When a release moves or renames a control, the page shows up as drift, with the missing control named. It also lists recent code changes that touched documented screens, and pages whose translations are behind.

A sudden wall of "drift" right after a new version is usually a failed run (an expired login or a slow site), not sixty broken pages. Claude checks for this before reporting; if you see it on the bench, ask Claude to rerun the check.
