Goal of this page. Get the Claude desktop app installed on your Mac, signed in, and connected to the systems the toolset uses. One-time setup; allow about 30 minutes.

Two words you'll see (full glossary in Part 7):

  • Connector: a secure link that lets Claude read and write in a system you already use, such as Confluence, Jira or GitHub. You approve each one and can disconnect it at any time.
  • Plugin: a package of our house instructions and safety checks for Claude. Part 2 installs them.

Step 1: Install the Claude desktop app

  1. In a browser, go to claude.ai/download and download the macOS version.
  2. Open the downloaded file and drag Claude into your Applications folder, then open it from there.
  3. If macOS asks whether you are sure you want to open an app downloaded from the internet, choose Open.

Step 2: Sign in

Sign in with the account Casey set you up with (the one that has access to the OpenELIS work and the "OpenELIS User Manual" project). If you are not sure which email to use, ask Casey.

Step 3: Connect the tools Claude needs

Connectors are managed in the Claude app's settings. For each one below, choose Connect and approve access in the window that opens. If a label in the app differs from this page, ask Casey.

ConnectorWhat it is forWhat you approve
Atlassian (Jira and Confluence)Reading Jira tickets, and reading and publishing Confluence pagesSign in with your UW Atlassian account and allow access to uwdigi.atlassian.net
GitHubReading the OpenELIS code, releases, the QA harness and the docs toolingSign in to GitHub and grant access to the DIGI-UW organization
Control your MacLets Claude run the capture harness, the freshness check and the publisher on your Mac, where your publishing key livesThe macOS permission described below
Claude in Chrome (recommended)Lets Claude look at a page in your own Chrome to confirm what a screen really showsInstall the Chrome extension when the app offers it

"Control your Mac" needs a macOS permission. The first time Claude uses it, macOS asks you to allow Claude under System Settings > Privacy & Security > Accessibility (and possibly Automation). Turn Claude on there.

Step 4: Work inside the project

Manual work happens in the claude.ai project "OpenELIS User Manual". It holds the notes from every past session, so Claude knows what was done before. Ask Casey to share it with you, and start your manual chats from inside it.

Done with Part 1 when: the app is installed, you are signed in, the connectors are connected, and you can open the OpenELIS User Manual project. Next: Part 2: Install the OpenELIS plugins.
