Vector Surveillance

At a glance

PurposeRun entomological and vector-borne-disease surveillance: register field collections of mosquitoes, larvae, fleas and rodents, identify the species present, and localize which specimens carry a pathogen.
What makes it differentA vector order is organism-based — instead of a patient you record the animal/organism type, the trap it came from, and how many specimens are in the pool. The pool is tracked as individual specimen barcodes through the lab.
You’ll end up withIdentified specimens on the Vector Identification worklist, pools deconvoluted into sub-pools to find the carrier, and (optionally) standardized field-survey indices computed automatically.
Who does thisLaboratory analysts and entomology technicians. Access is set by user permissions.
Before you startThe species list, trap types, sampling sites, and organism sample types must already be configured by an administrator — see Admin — Vector Surveillance Reference Data.
WhereMain menu → Orders → Add Vector Order; the identification worklist is at Results → Vector Identification.

Create a vector (pooled) order

Step 1. Open Orders → Add Vector Order → Enter Order and select the Sampling Site. Under Animal / Organism 1, choose the organism Sample Type from the taxonomy (for example Adult Mosquito, Mosquito Larva, Flea, or Rodent). The Lifecycle Stage, Trap Type and Quantity in Pool fields apply once a sample type is chosen.

{{IMG:01-order-entry.png}}

Figure 1. The top of the vector order entry form — lab number, collection date, and sampling site.

{{IMG:01b-order-organism.png}}

Figure 1b. The Animal/Organism section completed (example data) — Sample Type Adult Mosquito, Lifecycle Stage Adult, Trap Type BG-Sentinel Trap, Quantity in Pool 25, with a test selected under Order Tests.

Step 2. Choose the Trap Type the specimens came from and set Quantity in Pool (for example 25). Open Tests & Panels — required and select at least one test from the list (for example a Wolbachia sequencing or species-identification test).

Note — required test. The order will not save until at least one test is selected, and the Lab Number must be a valid generated accession (use Generate Lab Number). Choose Save & Next; the pool then expands into one barcode per specimen (for a pool of 25, the lab numbers run from .2 through .26).

Move the order through its stages

A vector order moves through the wizard stages shown at the top of the form: Enter Order → Label & Store → QA Review → Complete.

Step 3. On Label & Store, print the order and per-specimen labels, then either assign a storage location for each sample or tick skip storage, and choose Save & Next. For the storage hierarchy and how to assign or locate samples, see Sample Storage Management.

{{IMG:08-label-store.png}}

Figure 2. The Label & Store stage, listing the order label and the per-specimen pool labels with their barcodes.

Step 4. On QA Review, complete the checklist (sampling site correct, sample types and tests correct, labels printed, storage assigned), then choose Submit to release the order.

{{IMG:09-qa-review.png}}

Figure 3. The QA Review stage with the completed pre-submission checklist and order summary.

Step 5. After Submit, the order reaches Complete — a confirmation showing the lab number, organism, quantity in pool, and a Processing status. From here you can start a new order.

Figure 4. The Complete confirmation for the submitted order.

Identify species

Step 3. Open Results → Vector Identification. Submitted pools appear automatically. Use the Status filter and search to find a lot.

{{IMG:02-worklist.png}}

Figure 5. The Vector Identification worklist, listing pending lots with their sampling site, group, progress, ID status, and deconvolution status.

Step 4. Select a lot to expand it. A Species Distribution summary appears above a per-specimen table, with each pool and sub-pool and its specimens.

{{IMG:03-expanded-lot.png}}

Figure 6. An expanded lot showing the Species Distribution bar and the per-specimen table, including sub-pools.

Step 5. On a specimen row choose Identify. Set the Species (type-ahead from the configured species list), Method (Morphological, Molecular, or Morphological + Molecular), Confidence (Confirmed or Presumptive), and optionally the Lifecycle Stage and Notes, then choose Save Identification. The specimen updates to its species and confidence and the progress counter advances.

{{IMG:04-identify.png}}

Figure 7. The inline Identify form with Species, Method, Confidence, and Lifecycle Stage.

Deconvolute a pool (Split into sub-pools)

Deconvolution breaks a pool into smaller sub-pools, or down to individuals, so you can narrow down which specimen carries the pathogen.

Step 6. On the pool row choose Split. Set How many pools? (or Split to individuals), pick an Assignment method (Assign randomly, Auto sub-pool by species, or Assign manually), and select the tests for the sub-pools.

{{IMG:05-split-modal.png}}

Figure 8. The Split into Sub-pools dialog with pool count, assignment method, and tests for the sub-pools.

Step 7. Choose Preview Grouping to review the proposed sub-pools, then Save Pools. The sub-pools are created with their own lab numbers (for example P01-S1 through P01-S5), the parent's Decon column shows Decon in progress, and identified specimens carry their species into the sub-pool. Sub-pools can themselves be split for iterative deconvolution.

{{IMG:06-split-preview.png}}

Figure 9. The proposed sub-pool grouping preview before saving.

Optional: programs and field-survey indices

Programs are optional additional information on an order. They exist separately for the clinical, environmental, and vector domains and can be created and edited within the application — see Admin — Program Entry & EQA Program Management. Selecting a program reveals its own Additional Order Information fields — you only add a program when the order needs it.

For example, selecting the Vector Field Survey program reveals an Additional Information — Vector Field Survey section. Enter the larval survey counts (houses and containers examined and positive) and the pupal survey counts (pupae and population at risk). The preview computes the House Index, Container Index, Breteau Index, the ABJ larva-free rate, and Pupae-Per-Person, and flags when the ABJ is below the 95% Kemenkes target.

Figure 10. The Vector Field Survey section with the larval and pupal inputs and the computed indices, including the ABJ target flag.

Results and validation

Vector results are entered and validated on the same screens as other results — see the Results and Validation sections of the manual.

Field reference

FieldNotes
Sampling SiteThe vector “patient” / collection location.
Sample Type (organism)Mosquito / larva / flea / rodent taxonomy; configured in admin.
Trap TypeThe trap the specimens came from; configured in admin.
Lifecycle StageAdult, Larva, Pupa, or Egg.
Quantity in PoolNumber of specimens; drives the per-specimen barcodes.
Species / Method / ConfidenceSet on the Identify form.
Sub-pool IDThe P01-Sn lineage produced by deconvolution.
HI / CI / BI / ABJ / PPIField-survey indices computed from the survey counts.

Tips

  • Pool specimens are barcoded individually; deconvolution preserves the pool-to-sub-pool lineage for the consolidated record.
  • Selecting a compliance standard or program does not auto-select tests — choose the tests yourself.
  • Species, trap types, and sampling sites are maintained under Admin — Vector Surveillance Reference Data.
