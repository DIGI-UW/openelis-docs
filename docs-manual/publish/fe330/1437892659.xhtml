At a glance

Purpose

Register and maintain the organizations OpenELIS works with — referring clinics, referral labs, health districts and regions, sampling sites, and vendors — so they can be selected on orders and reports.

You'll end up with

An active organization record, searchable and selectable wherever organizations are used (for example, the requesting facility on an order).

Who does this

Administrators. Access is set by user permissions and can be configured by your administrator.

Before you start

The organization's name and, where relevant, its parent organization, address, CLIA number, and which type(s) of activity it performs.

Where

Main menu → Admin → Organization Management.

Organization Management is the master list of the organizations OpenELIS references — the facilities that order tests, the labs samples are referred to, the administrative regions they sit in, and the sites where environmental and vector samples are collected. Each row shows the organization's name, parent, prefix, active status, address, and CLIA number. From here you add new organizations, modify existing ones, or deactivate those no longer in use.

Step 1 — Open Organization Management and find an organization

  1. Open Main menu → Admin → Organization Management.

Organization managent

  1. The list shows every organization with its name, parent, prefix, active status, address, and CLIA number. Type in Search By Org Name to filter the list.

Search by organization name

  1. Tick a row's Select checkbox to enable the Modify and Deactivate actions for that organization.

Select row

The Organization Management list, with the search bar and the Modify, Deactivate, and Add actions.

Step 2 — Add or modify an organization

  1. Click Add to create a new organization, or select a row and click Modify to edit one.

Click add button

  1. Enter the Org Name (required). Optionally add an Org prefix, Internet Address, Street Address, City, and CLIA Number, and set Is Active.

  2. Choose a Parent Org if this organization belongs under another in the hierarchy.

  3. Under Type of Activity, tick every role the organization plays — for example referring clinic, referralLab, Health District, or sampling site.

  4. Click Save. Save stays disabled until the required fields — Org Name, Is Active, Parent Organization, and at least one Type of Activity — are set.

The Add Organization form: organization details at the top, and the Type of Activity roles below.

Type of Activity options

An organization's Type of Activity determines where it can be selected in OpenELIS. Tick every role that applies — an organization can hold more than one. The two most easily confused are referring clinic (a site that requests tests) and referralLab (a lab that samples are sent to).

Option

What it means

referring clinic

A site that requests tests from this laboratory — the ordering facility. Appears as a requesting organization when an order is entered.

referralLab

A laboratory that samples are sent to for testing this lab does not perform — the destination of an outbound referral.

patient referral

The clinic that referred the patient to this laboratory.

TestKitVender

An organization that supplies test kits (for example, HIV test kits).

Health District

The administrative health district a facility belongs to.

Health Region

The administrative health region a facility belongs to.

dept

An internal department within an organization.

sampling site

A site where environmental or vector samples are collected for monitoring.

Field reference

Field

Notes

Org Name

Required. The organization's display name, shown wherever organizations are selected.

Org prefix

Optional short code (for example, FACILITY_ORG).

Is Active

Required. Y or N; inactive organizations are hidden from selection but retained.

Internet Address / Street Address / City

Optional contact details.

CLIA Number

Optional laboratory identifier.

Parent Org

Required. Places this organization under another in the organization hierarchy.

Type of Activity

Required. One or more roles that determine where the organization can be used — see Type of Activity options above.

Notes

  • Organizations are deactivated, not deleted — select a row and use Deactivate to retire one while preserving its history and existing links.

  • An organization can hold several activity types at once (for example, both a referring clinic and a sampling site).

  • The sampling sites used by environmental and vector surveillance are organizations carrying the sampling site activity type.
