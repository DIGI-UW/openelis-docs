OpenELIS 3.3.0. Custom Data Export and My Report Queue are new in 3.3.0 (not yet released at the time of writing; stories OGC-479, OGC-481 and OGC-483 in Acceptance). This page is a draft for review.

How-to · Lab managers and QA officers

At a glance

Purpose

Build a CSV extract of samples, tests, results and turnaround times yourself, without SQL, and rerun the same report for a new period.

You'll end up with

A CSV file with the columns you chose, in your order, and optionally a saved report you can rerun.

Who does this

Lab managers and QA officers. Access is set by user permissions and can be configured by your administrator; patient name and identifier fields need extra permissions.

Before you start

Know the question the CSV must answer, the period (up to 90 days), and the lab sections it covers.

Where

Main menu → Reports → Custom Data Export

Step 1: Start an export

  1. Open Main menu → Reports → Custom Data Export. The landing page offers Create a new export (Start a new export) and Use a saved report, with My Report Queue at the top right. When you have a report in progress, Continue current export returns to it.

    Figure 1. Custom Data Export before any report has been saved.

  2. Select Start a new export. The builder has three steps: Choose columns, Set Filters and Review & Submit. First choose one report type, so every CSV row has a clear meaning: Sample & Testing (orders, results, patients and turnaround times), Referrals (tests referred to other labs) or Non-Conformance (rejected samples and non-conforming events). You can change the type until you select fields.

    Figure 2. Choosing the report type.

Step 2: Choose the columns

  1. For Sample & Testing, choose the CSV layout; Spreadsheet: tests in columns gives one row per specimen with tests as columns.

  2. Available fields are grouped: Sample and order, Patient, Turnaround time, Configured tests, Turnaround by test, Configured result components, Turnaround by result component and Additional questions. Expand a group or type in Find a field, then select + Add on each field you want; Add all shown adds every field in view.

  3. The fields appear, numbered, under Your CSV columns. Drag a handle or use the arrows to change the order (arrow keys move the focused handle; Home and End move it to the first or last position), and the cross to remove one. The CSV preview shows the header in the order the file will have.

    Figure 3. Eight columns chosen, including a test result and its received-to-validated time.

  4. Select Next: Set Filters. It stays unavailable until at least one column is chosen.

Step 3: Set the filters

  1. Under Date Range, set Date from and Date to. The range uses specimen collection dates in UTC, includes both dates, and can be at most 90 days.

  2. Under Scope Filters (Optional), narrow the report to Lab sections (only the sections you have access to are offered), Tests and Result statuses (Finalised by default). Show more filters lists Sample Status, Priority and Referring Site, marked Not yet connected.

    Figure 4. Thirteen days of finalised results.

  3. Select Next: Review & Submit.

Step 4: Review, save and generate

  1. The review shows the report type and layout, the date range and filters (with Change), and the selected fields (with Edit report). A message says whether the CSV will download straight away or be generated in the background; a longer period goes to the background.

    Figure 5. Review & Submit: this CSV will be generated in the background.

  2. To reuse these settings, tick Save these report settings for later, enter a Report name and select Save report settings. The page confirms Saved as and the name. The saved report keeps the fields and filters but never the reporting period. Once saved, Update shared report and Save a copy are offered.

    Figure 6. The report settings saved as a shared report.

  3. Select Generate CSV. When it is ready, Your current report shows Ready to download with the row count, and Download CSV. The file name is generated automatically; a custom name is not yet connected.

My Report Queue

My Report Queue lists your exports with Job Name, Report, Date Range, Status, Rows / File Size and Submitted At. A finished job offers Download CSV and Details. Active jobs refresh on their own. The page says failed exports can be retried, queued work cancelled and expired reports rerun with fresh dates; deleting a job is not yet connected.

Figure 7. My Report Queue with three finished exports.

Rerun a saved report

  1. On the landing page, Use a saved report lists the saved reports with their field count, noting that the reporting period is never saved. Shared reports opens the full list.

    Figure 8. A saved report on the landing page.

  2. Select Use report. The builder opens on Set Filters with the saved fields and filters and asks you to Choose fresh dates before running this report. Set the dates and continue as in Step 4.

    Figure 9. A saved report reopened, waiting for fresh dates.

Tips and notes

  • The date filter uses specimen collection dates. Orders with no collection date recorded may not appear.

  • Saved reports are shared: the landing page calls them Shared reports, and saving offers Update shared report.

  • On 3.3.0-SNAPSHOT the date fields show month first (10/01/2026 for 1 October), and many test names in Configured tests appear in French (for example Hémoglobine(Whole Blood)); searching "Hemoglobin" finds nothing.

Not covered on this page

  • The Referrals and Non-Conformance report types, other CSV layouts, and the locked patient fields for users without the identifying-data permissions.

  • Cancel, Retry and Re-run in the queue, job expiry, and the in-app notification when a job finishes.
