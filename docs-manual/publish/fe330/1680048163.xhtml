At a glance

Purpose

Know where statistical quality control lives in OpenELIS and check each day whether any control has failed.

You'll end up with

A view of instrument QC status, bench and rapid-test controls, and any violations that need action.

Who does this

Quality officers and supervisors, and bench staff who run controls. Access is set by user permissions and can be configured by your administrator.

Before you start

At least one active control lot (see Receive and activate a control lot).

Where

Main menu → Quality Assurance → Statistical QC.

What is in Statistical QC

Menu item

What it is for

QC Dashboard

Status summary with three tabs: Instruments, Alerts and Bench QC.

QC Alerts

Opens the dashboard on its Alerts tab.

Control lots and their target statistics.

The Westgard rule sets configured per analyzer and test ("Configured Rule Sets").

Check QC status each day

  1. Open QC Dashboard. The four tiles at the top show Instruments In Control, Warning Status, Out of Control and % Instruments In Control (called Overall QC Pass Rate on 3.2.2.0). Last Updated shows when the figures were read; Refresh and Export sit beside it. Export opens Export QC Data, where you choose the Instrument, the Control Level (All levels by default) and a Start Date and End Date, then Export CSV or Export PDF. On the test server, with no instrument to choose, both export buttons were unavailable.

  2. The Instruments tab lists each instrument with its Type, Location, Status, Analytes, Recent Violations, Last Update and Actions. Use Search instruments to find one.

Figure 2. The QC Dashboard on its Instruments tab (3.3.0). This instance has no instruments connected, so the list is empty.

  1. Open the Bench QC tab to see controls recorded without an analyzer, such as rapid-test controls. Each row shows the Lab unit, Test, Source, Controls run, how many Failed, and when the last one was run. Filter with Source.

Figure 3. The Bench QC tab with one rapid-test control run for HIV Rapid Test in Serology, marked as failed.

  1. Open the Alerts tab (or QC Alerts in the menu). Active QC Violations lists violations not yet acknowledged; Acknowledged Violations lists those already dealt with. Choose the Time Period to look back over, for example Last 72 Hours.

Figure 4. The Alerts tab with no active or acknowledged violations in the last 72 hours.

Acknowledging a violation has not yet been verified on a live instance, because no violation was available to act on. Confirm before publishing.

Tips

  • A failed bench control does not appear on the Alerts tab: with the failed HIV Rapid Test control in Figure 3 on the dashboard, Alerts showed no violations. Check the Bench QC tab as well as Alerts.

  • These pages show Analyzers › Quality Control Dashboard in the breadcrumb even when reached from Quality Assurance. This is a known inconsistency, not a different page.

  • How rapid-test and manual control results are recorded is not yet documented in this manual.

Not yet available
