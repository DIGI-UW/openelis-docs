How-to · Reception and sample collection staff

Part of the clinical order pipeline: Enter Order → Prepare Samples → Sample check

panel_c1

This page describes OpenELIS 3.3.0. Prepare Samples replaces the old Collect step and takes over labelling and storage from Label & Store. Updated on 12 October 2026 for Refer Out from this step, recording a test done elsewhere, and the Handling group. Sites on 3.2.x use the Collect and Label & Store steps; see Collect samples for a clinical order (before 3.3.0).

At a glance

Purpose

Record each tube for an entered order: what it is, when and by whom it was collected, how it arrived, its labels and where it is stored.

You'll end up with

The order's samples saved with collection and receipt details, labels printed, and the order status Samples prepared.

Who does this

Reception or sample collection staff. Access is set by user permissions and can be configured by your administrator.

Before you start

An order saved on Enter Order, and the tubes in hand.

Where

Save and next on Enter Order, or Main menu → Order → Add Clinical Order → Prepare Samples and scan the lab number

Steps

  1. Open the order. Save and next on Enter Order lands here with the order loaded. Otherwise scan or type the lab number in Scan barcode or enter lab number. The order card shows the lab number, the status (Entered), the patient, the samples with their test count, and the step counter. Arriving from Save and next, the page title carries a Saved tag.

    Figure 1. Prepare Samples straight after Save and next: Enter Order is Done, the order is Entered, and three Serum tests are listed under Requested Tests.

  2. Check the Requested Tests table. Each ordered test is a row with its Compatible Sample Types (green tags) and its Sample Assignments, for example Serum (Sample 1). A Multi-Sample Collection Example under the table, headed When multiple sample types are needed, shows Plasma (Sample 1) + Plasma (Sample 2) = Creates separate tubes for each type.

  3. Record a test already done elsewhere, if any. Each Requested Tests row has an options menu (⋮) at the right with Mark tested elsewhere. Choosing it adds a purple Tested elsewhere tag naming the performing laboratory, a Reported value box (Result reported by another laboratory) and a Performing laboratory list. On the reference order the performing laboratory was filled in with the requesting site, Port Moresby General Hospital; change it if another laboratory did the test.

    Figure 2. The options menu on the GOT/ASAT row, with Mark tested elsewhere.

    Figure 3. GOT/ASAT marked as tested elsewhere, with a reported value of 31 and the performing laboratory.

  4. Add tests if needed. Add Tests or Panels is for a test the clinician asked for after the order was entered, or one that only becomes appropriate with the specimen in hand. It is listed per sample type with that sample type's current test count (Serum with a count of 3 on the reference order).

  5. Record consent if your site captures it. Informed Consent holds one checkbox, Patient has provided signed consent.

  6. Fill in each sample card. Under Samples, each tube has a card (Sample 1, Sample 2…) listing its Assigned Tests. Above the cards, Received by … (you) names you as the person receiving, with a Change link. On each card:

    • Sample Type, Quantity and Unit (mL, slides, tubes, uL).

    • Collection Method. Its list comes from your site's configuration and may offer only Select.

    • Collection Location (GPS), a collapsed panel marked Optional with an Expand link.

    • Collection Date (its help text says it defaults to today; correct it if the sample was collected earlier), Collection Time (filled with the current time on the reference site) and Collector.

    • Handling: the requirement for the tests on this tube (for example Required: No requirement), Arrived as (Not recorded, Room temperature, Refrigerated 2 to 8 °C, Frozen, On ice, Dry ice) and Measured temperature (°C).

    • Stored at, which read Not stored yet for a tube with no location.

    • Received at Lab: Received Date and Received Time, marked Auto-filled from server.

    Add Sample adds another tube, for example when more was drawn than expected or a different sample type is needed; print its labels from its card or the Labels section. Remove Sample on a card removes one.

    Figure 4. The Sample 1 card filled in: 4 mL of Serum, collector Grace Tau, Handling with no requirement, arrived refrigerated at 6 °C, not stored yet, and the server-filled received date and time.

  7. Set and print labels. The Labels section has an Order Labels table (one Order row, column Order Label) and a Sample Labels table with one row per tube (for example DEV01260000000000099-1 Serum, column Specimen Label). Each quantity starts at the label preset's default, tagged Preset default, and can be changed with the minus and plus buttons. Total labels adds them up.

    Before the first save the total is tagged Prints after save. Once the samples are saved, Print Labels on a sample card and Print all labels each open the labels as a PDF in a new browser tab, ready to print. Each table row also has its own printer icon under Print Labels.

    Figure 5. Order and sample label quantities from the presets, with Print all labels.

  8. Store the tubes, or skip storage. Under Location, an Unassigned Samples notice lists tubes with no location. For each tube, search for a storage location (type 2 or more characters), or pick it level by level: Room, Device, Shelf, Rack, Box and Position (optional). Condition Notes records anything about storage conditions. Tick Skip storage for unassigned samples when the tubes go straight to the bench.

    Storage is not required to continue: Save and next succeeded with no location chosen and Skip storage unticked.

    Figure 6. The Location section for one unassigned Serum tube.

  9. Refer a tube out, if it is going to another laboratory. Once the samples are saved, Refer Out / Subcontract lists each tube with Sample ID (the lab number with the tube number, for example DEV01260000000000507-1), Sample Type, Tests, Reference lab and Subcontract Status (In-house until referred). Refer out all in-house samples sits above the table. On a new order, save first: before the samples are saved the section reads No samples available for referral.

    Refer Out on a row opens a form under it:

    • Reference lab, required: a list of the reference laboratories set up at your site.

    • Reason, optional: Test not performed, Confirmation requested, Further testing required, Reagent expired, Reagents unavailable, Equipment failure, Verification of EQA, Specimen sent for serotyping, EQA by Repeat Testing or Other.

    • Agreement Reference, Handoff Date, Handoff Time and Expected Return Date.

    • Chain-of-Custody Contact Name, Chain-of-Custody Contact Phone and Chain-of-Custody Contact Email. The phone number must start with a country code, for example +675; without one the form says Enter a valid phone number with country code prefix.

    • Notes.

    Figure 7. The Refer Out form for one Serum tube: Central Public Health Laboratory, Confirmation requested, and a chain-of-custody contact.

    Press Save Referral. The row then shows the reference lab with the status Pending save: the referral is kept only when you save the step with Save and exit or Save and next.

    Figure 8. After Save Referral: the tube shows Central Public Health Laboratory and Pending save until the step is saved.

    On the reference order, Save and exit then returned to the Order Dashboard, where the order read Referred out, All 3 tests referred to Central Public Health Laboratory, with progress 3/3 and Open as its action. Reopened, the tube's Subcontract Status read Draft. That is the status of the referral record itself, separate from the order's Referred out status; how a referral moves on from Draft is not covered on this page.

    Figure 9. The Order Dashboard after the referral was saved: the order is Referred out, with all 3 tests referred to Central Public Health Laboratory.

  10. Save. Save and next saves the samples and opens Sample check; Prepare Samples shows as Done and the order status becomes Samples prepared. Save and exit saves and returns to the Order Dashboard with the order highlighted. Discard and Back are also in the footer, with Report NCE below Back for reporting a non-conforming event on this order.

    Every sample must carry at least one test before you can continue. A sample with none is listed under To continue to Sample check, for example DEV01260000000000100-1 Whole Blood has no tests. Add them on Enter Order or remove the sample, with Save and next disabled and Save and exit still enabled.

Field reference

Field

Notes

Requested Tests

Test/Panel, Compatible Sample Types, Sample Assignments, and an options menu per row.

Mark tested elsewhere

Row menu. Adds Reported value and Performing laboratory for a test another laboratory has done.

Add Tests or Panels

Per sample type, for tests added after entry.

Patient has provided signed consent

Checkbox under Informed Consent.

Sample Type / Quantity / Unit

Unit: mL, slides, tubes, uL.

Collection Method

List configured per site.

Collection Location (GPS)

Optional, collapsed.

Collection Date / Time

Date defaults to today; time was filled with the current time.

Collector

Free text, placeholder COL-0000.

Arrived as / Measured temperature (°C)

Arrival condition and temperature.

Received Date / Time

Auto-filled from the server.

Order Label / Specimen Label quantities

Start at the preset default.

Location

Search, or Room → Device → Shelf → Rack → Box → Position. Optional.

Skip storage for unassigned samples

For tubes processed immediately.

Condition Notes

Free text about storage conditions.

Refer Out

Per tube, once saved. Reference lab is required; Reason and the chain-of-custody fields are optional. Phone needs a country code.

Tips

  • An order saved from Enter Order with Save and exit can still have a sample with no tests. It cannot leave Prepare Samples that way: add the tests, or remove the empty sample.

  • A referral is not kept until the step is saved. If you leave the page after Save Referral without Save and exit or Save and next, the tube is still In-house.

  • Labels print only for saved samples. On a new order, save first, then print from the sample card or with Print all labels.

  • If your site has no storage rooms set up, the Room list is empty. Storage locations are managed under Storage Management.

Not yet available

  • Proposed tubes from the test catalog's container types, and body sites for swabs.
