Part of: Test Catalog Management: workflow overview

How-to · Lab administrators

At a glance

Purpose

Create or edit a label preset (a reusable barcode label definition: size, barcode type, scope, quantities and the fields printed on it), and set the one site-wide barcode choice: where pre-printed label numbers come from.

You'll end up with

A label preset available for printing and for use by the test catalog.

Who does this

Lab administrators. Access is set by user permissions and can be configured by your administrator.

Before you start

The label stock you print on: its height and width in millimetres, and the barcode type your scanners read.

Where

Main menu → Admin → Label Presets

panel_c1

This page replaces the old Barcode Configuration screen. Barcode label settings used to live on a separate Barcode Configuration page with global Number, Elements and Dimensions sections. They are now set per preset here, with one exception that stays laboratory-wide: where pre-printed label numbers come from, in the Site-wide Barcode Settings card above the list. The Barcode Configuration entry on the Admin home page still exists; its address now opens this page.

The Content fields editor and the Site-wide Barcode Settings card are new in OpenELIS 3.3.0. On 3.2.x the rest of this page applies.

A label preset defines a printable barcode label: its dimensions, its barcode type, the scope it applies to (one label per order, or labels per sample), how many labels print by default and at most, and the fields printed above the barcode. OpenELIS ships five System presets: Order Label, Specimen Label, Block Label, Slide Label and Freezer Label, all CODE_128 and 25 x 76 mm. You can add your own.

Step 1: Open Label Presets

  1. Open Main menu → Admin → Label Presets. The Site-wide Barcode Settings card is at the top (see Site-wide barcode settings below). Under it, the list shows each preset's Name, Barcode Type, Dimensions, Scope and Status. Built-in presets carry a System tag. Type in Search presets... to filter the list.

    Figure 1. Label Presets, with the Site-wide Barcode Settings card above the five System presets.

  2. To change a preset, open its row Actions menu (⋮) and choose Edit. Duplicate in the same menu starts a new preset from an existing one.

    Figure 2. The Actions menu on a preset row: Edit and Duplicate.

Step 2: Add a preset

  1. Click Add Preset. The Add Label Preset dialog opens.

  2. Under Basic Info, enter a Preset Name. Active is ticked by default.

  3. Under Dimensions (mm), set Height (mm) and Width (mm).

  4. Under Barcode Settings, choose the Barcode Type: CODE_128, QR or DATAMATRIX.

  5. Under Print Scope & Quantities, tick Order, Sample or both. Each box you tick shows its own pair of quantity fields: Default per Order and Max per Order, or Default per Sample and Max per Sample. A new Sample scope starts at 1 by default and 10 at most. The maximum is the most labels that can be printed.

    Figure 3. A 13 x 38 mm DATAMATRIX cryovial label, printed per sample: 2 by default, 4 at most.

    At least one scope is required. If neither box is ticked when you save, the dialog stays open and shows At least one print scope (Order or Sample) must be selected.

    Figure 4. Saving with no scope ticked.

  6. Under Content fields, choose what the label prints above its barcode. Lab Number is always in position 1, tagged Always first, and is always required. To add a field, pick it in Add a field and click Add. The fields you can add are Patient Name, Patient Date of Birth, Patient ID, Patient Sex, Site ID, Collection Date and Time, Collected By, Tests, Specimen Type, Block ID, Slide ID, Stain Type, Case Number, Storage Location and Expiry Date. Each added field gets a position, a Required box, up and down arrows to change its order, and a bin button to remove it.

    Figure 5. Content fields for the cryovial label: Lab Number, then Patient ID (required), Collection Date and Time, and Storage Location.

  7. Click Save. The dialog closes and the new preset appears in the list.

    Figure 6. The saved Cryovial Label preset, found with Search presets.

The content fields decide what every printout of that preset shows, including the Print Bar Code Labels page.

Site-wide barcode settings

The Site-wide Barcode Settings card, tagged Applies laboratory-wide, holds the one barcode setting that is not per preset. Under Pre-printed label numbers come from, it decides where the numbers on pre-printed labels (Order → Print Bar Code Labels → Pre-Print Barcodes) come from:

  • The same format and number pool as order entry: pre-printed labels take the next numbers of the ordinary lab number series. This is the default.

  • A separate pre-printed series: pre-printed numbers start with a Prefix of exactly 4 letters or digits, then the year and a sequence number.

  1. Choose one of the two options. Prefix is enabled only for the separate series.

  2. For a separate series, enter the 4-character prefix. A prefix of any other length is refused when you click Save settings: the field shows The prefix must be exactly 4 letters or digits and nothing is saved.

    Figure 8. A 3-character prefix refused.

  3. Click Save settings.

Note: a pre-printed label exists before any order, so patient details stay blank on it until its number is attached to an order.

Tips

  • The quantity field labels follow the scope: they read "per Order" or "per Sample". If you see only one pair, only one scope is ticked.

  • To stop using a preset, open it with Edit and clear Active rather than recreating it, so existing history stays readable.

Related: the Test Catalog editor's Labels section lets a test suggest one of these presets at order entry. Barcode label printing during order entry is covered in the order entry pages.
