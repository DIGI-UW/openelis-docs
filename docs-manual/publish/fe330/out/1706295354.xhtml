OpenELIS 3.3.0. This page describes the Locations & Organizations admin introduced in 3.3.0 (not yet released at the time of writing). It is a draft for review; see also Admin: Manage organizations (3.3.0).

At a glance

Purpose

Load or update organizations, wards and departments, sampling sites and geographic areas in bulk from CSV files, and check every change before it is saved.

You'll end up with

The records in your files added or updated, and a result report you can download.

Who does this

Administrators. Access is set by user permissions and can be configured by your administrator.

Before you start

CSV files in the same format the system uses at installation. Download a template from the page if you are starting from scratch.

Where

Main menu → Admin → Locations & Organizations → Import / Export

Import / Export reads three kinds of file:

Area

File name pattern

What it holds

Geographic levels

*-levels.csv

The names of the levels of your country's divisions, top first. Columns level,typeName, for example 1 Region, 2 Province, 3 District, 4 LLG (local-level government).

Geographic areas

*-values.csv

The areas themselves. One column per level, named after the level. Each cell is the area name, a %, then its code, for example Morobe Province%P-MOR. A row describes one path from the top level down; leave the lower cells empty for a shorter path.

Facilities, wards & sites

organizations-*.csv

Organizations, their wards or departments, and sampling sites, one per row, with type, code, name, parent, location, address, GPS, contact and other details.

Nothing is saved until you have reviewed the preview and applied it.

Step 1: Choose the files

  1. Open Main menu → Admin → Locations & Organizations → Import / Export.

  2. If you need a starting point, use the links under the drop area: Download template · Facilities, wards & sites, Download template · Geographic levels and Download template · Geographic areas. Each downloads a CSV with the header row and one or more example rows.

  3. Under 1. Files, drag your CSV files onto the drop area or click it to browse. You can add several files at once; load levels and areas together when you set up areas for the first time.

  4. Each file is listed with an Area list. OpenELIS picks the area from the file name pattern. Check it, and change it if your file is named differently (a file called png-areas.csv is not recognised as areas, so set it to Geographic areas). Remove takes a file off the list.

    Figure 1. A levels file and an areas file chosen, each with its Area set.

  5. Under 2. Import mode, choose:

    • Add & update: add new records and update matching ones. Nothing else changes. This is the default.

    • Replace: also deactivate records of the types in the file that the file does not include. Nothing is deleted.

Step 2: Preview the import

  1. Click Preview. A message repeats the import mode and says Nothing has been saved. A summary counts the rows that are New, Updated, Unchanged, Reactivated, Deactivated, Needs decision and Rejected.

  2. The table below lists each row with its Line in the file, its Outcome, Type, Code, Name and any Detail. Read it before applying, especially for Replace imports and rows that are rejected or need a decision.

    Figure 2. The preview of a first load of Papua New Guinea areas: 11 new rows (4 levels and 7 area paths), nothing saved yet.

  3. To go back without importing, click ← Back to List.

Note: in the preview, an areas row is counted once, by its lowest area. The higher areas on the same row (the region, province and district above an LLG) are created too when you apply, as the Geographic Areas page then shows.

Step 3: Apply the import

  1. Click Apply. The Apply this import? dialog repeats the counts. Click Apply to save, or Cancel.

    Figure 3. The confirmation before anything is saved.

  2. When the import finishes, the page shows Import complete with the final counts and a Download result report button.

    Figure 4. The import applied. Recent imports lists the preview and the applied import, newest first.

Recent imports

The Recent imports list at the bottom of the page shows every preview and every applied import: the date and time, the user, whether it was a Preview or Applied, the mode (Add & update or Replace), the file names and the counts. Download result report on any row downloads that run's report.

Exporting

Export is not on this page. The Organizations and Sampling Sites pages have their own Import and Export buttons above the list; exporting is not yet documented.

Tips and notes

  • Set up geographic levels and areas before organizations and sites, so their Location can be filled in.

  • Use Add & update for routine changes. Use Replace only with a complete file, because records of the same types that are missing from it are deactivated.

  • Inactive records are hidden from order entry and other pickers. They still appear on existing orders and reports.

  • On a 1440 px wide screen the user column in Recent imports wraps the user name over two lines.

Not covered on this page

  • The Export buttons on Organizations and Sampling Sites, and the Import buttons there.

  • Rows that are rejected or need a decision, and Replace mode. These were not exercised on the test server.
