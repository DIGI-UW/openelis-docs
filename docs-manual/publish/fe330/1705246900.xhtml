How-to · Quality managers

At a glance

Purpose

Record the bodies that accredit your laboratory and the tests each one accredits, so that patient reports carry the right accreditation logo and you can show which accredited tests take part in EQA.

You'll end up with

An active accrediting body with its logo, the tests in its scope, and the logo printed on patient reports that include those tests.

Who does this

Quality managers. Access is set by user permissions and can be configured by your administrator.

Before you start

The accrediting body's code and name, the date your accreditation expires, the list of accredited tests, and the body's logo as a PNG or JPEG (at least 64 x 64 pixels, up to 500 KB).

Where

Main menu → Quality Assurance → QMS & Improvement → Accreditation

The Test Accreditation page tracks accrediting bodies and per-test enrolment. It drives the accreditation logos on patient reports and answers an inspector's question: which of the tests you claim as accredited take part in external quality assessment (ISO 15189 §7.7).

Step 1: Add the accrediting body

  1. Open Main menu → Quality Assurance → QMS & Improvement → Accreditation. Tiles count the Bodies, how many are Active, Expiring Soon and Expired; the bodies currently in force are named under them. Below are three sections: Accrediting Bodies, Enrolled Tests and EQA Coverage of Accredited Scope.

    Figure 1. Test Accreditation with one body in force.

  2. Select Add body. Enter the Code (2 to 16 characters: capitals, digits and hyphens; it cannot be changed later) and the Name, and pick the date Accreditation expires.

  3. Under Show the logo on a report when, choose Any accredited test is on the report, or A percentage of the report's tests are accredited, which adds a Threshold (%) (80 by default). Set the Display order if more than one logo may print, and leave Active on.

  4. Under Logo, select Upload file and choose the logo. The file name appears under the button. Select Save.

    Figure 2. Adding an accrediting body: the percentage rule, display order, Active and the uploaded logo.

  5. The body is listed with its logo, code, name, expiry date, number of enrolled tests and status. The row's icons edit or delete it.

Step 2: Enrol the accredited tests

  1. Under Enrolled Tests, select Enroll tests. Choose the Accrediting body, then type in Tests and tick each accredited test. Optionally set Effective from. Select Save.

    Figure 3. Enrolling haematology tests under the accrediting body.

  2. Each enrolled test is listed with its accrediting body, effective date, the body's expiry and its status, and can be filtered by body, status or test name. The trash icon removes an enrolment.

Step 3: Check EQA coverage

  1. EQA Coverage of Accredited Scope compares each body's accredited tests with your active EQA enrolments: Tests in Scope, Covered by EQA and the Gaps, naming each accredited test that has no EQA. Close a gap by enrolling in a scheme for that test (see EQA participant) or by documenting an alternative assessment.

    Figure 4. Five enrolled haematology tests; none yet covered by EQA.

What the patient report shows

When a patient report includes an accredited test and the body's rule is met, the report carries the body's logo at the top and the line Tests on this report are accredited by: followed by the body's name.

Figure 5. The top of a Patient Status Report for a full blood count, with the accreditation logo and statement.

Tips and notes

  • Choose the code with care; it cannot be changed after saving.

  • Keep the expiry date current. The Expiring Soon and Expired tiles show when an accreditation needs renewing.

  • On the test server the logo overlapped the end of the report title (Results of Analysis).
