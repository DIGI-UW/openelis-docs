OpenELIS 3.3.0. This page describes the Locations & Organizations admin introduced in 3.3.0 (not yet released at the time of writing). It is a draft for review; see also Admin: Manage organizations (3.3.0).

At a glance

Purpose

Record the fixed places where environmental samples are collected (a water source, a mosquito trap, an air monitor, a soil plot) so results can be compared over time at the same spot.

You'll end up with

An active sampling site with a code, a location, a GPS point and a contact person.

Who does this

Administrators. Access is set by user permissions and can be configured by your administrator.

Before you start

The site's name and code, and its geographic area. Geographic areas must be loaded first (see Admin: Manage geographic areas (3.3.0)).

Where

Main menu → Admin → Locations & Organizations → Sampling Sites

A sampling site does not order tests. It records where a sample was taken. Hospitals, clinics and laboratories are organizations, not sampling sites; open Organization or sampling site: which do I need? under the page description if you are unsure.

Step 1: Open Sampling Sites and find a site

  1. Open Main menu → Admin → Locations & Organizations → Sampling Sites. The list columns are Name, Code, Type, Location, Site type, In use (with the number still open in brackets), Active and Actions. With no sites yet, the list says No records yet. Add one, or import a file.

  2. Type in Search by name, code or any identifier, or pick an area in Location (includes areas beneath): choosing a province also lists the sites in its districts and LLGs. The chosen area shows as a tag with Clear filters. Status switches between Active, Inactive and All.

    Figure 1. Sampling sites filtered to Central Province, which includes the Laloki River intake in Hiri Rural LLG.

Step 2: Add a sampling site

  1. Click Add. A form opens in the list, with links at the top to its sections: Identity, Identifiers, Location, Contact and Site details.

  2. Under Identity, enter the Name (required) and, if you want, a Short name. In Description, include directions so someone else can find the exact spot.

  3. Under Identifiers, the first row is labelled Code and is marked as the Reporting code. Enter the site's code in Value; a sampling site needs one. You can type another label or pick one already used. Add identifier adds more rows. The reporting code shows as Code in lists, exports and reports, and every identifier is searchable.

    Figure 2. Identity and identifiers for a river water intake, with its reporting code.

  4. Under Location, type part of an area name in Location and pick from the list. Each suggestion shows the area's level and the areas above it. Pick the most specific area you know; a district is fine if you do not know the LLG. The chosen area's full path is shown under the field.

    Figure 3. Typing "Hiri" offers the district and the LLG, each with its path.

  5. Add Street address, City, State / Province and Postal code if they apply, and GPS latitude and GPS longitude in decimal degrees (WGS84). Under Contact, add a Contact name, Phone, Email and Website as available. Under Site details, choose a Site type and Environmental zone and type a Subtype. All of these are optional.

    Figure 4. Location, GPS point, contact and subtype filled in.

  6. Click Save. If the code is missing, nothing is saved: the page shows The record was not saved: A sampling site needs a code and marks the identifier row.

    Figure 5. Saving without a code.

    Once saved, a message confirms the site was added. The new row shows its code, the sampling site type tag and its location path, and the form stays open for editing, with History at the bottom.

    Figure 6. The Laloki River raw water intake added.

Step 3: Edit, check history, deactivate

  1. Click Edit in a site's row to open its form, change any field and click Save. Close in the row closes the form.

  2. Click History at the bottom of the form to see each change with its date and user. Filter by action narrows the list. The history is read-only and is kept for as long as the record exists.

  3. Use the Active switch to deactivate a site that is no longer sampled. Set Status to Inactive or All to find it again.

Tips and notes

  • Sites can also be loaded in bulk from the Facilities, wards & sites file on Import / Export, using the type sampling site.

  • The Site type and Environmental zone lists were empty on the test server; their values come from your site's configuration.

  • On 3.3.0-SNAPSHOT, the saved Short name shows the reporting code instead of what you typed. Check it after saving.

  • Inactive records are hidden from order entry and other pickers. They still appear on existing orders and reports.
