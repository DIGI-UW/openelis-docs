Statistical quality control (Westgard QC)

OpenELIS evaluates the control results your analyzers send against Westgard rules and shows the outcome on the QC Dashboard. Control results are never typed in: they arrive through the analyzer's electronic connection, are matched to an Active control lot for that analyzer and test, and are judged against the rule set configured for the pair.

Everything lives under Main menu → Analyzers → Quality Control: QC Dashboard, Rule Configuration and Control Lots.

Before QC can work

All five must be true: the analyzer is connected and Active; its control samples reach OpenELIS as control results; an Active control lot exists for the exact analyzer and test; the lot's identifier matches what the analyzer sends; and Westgard rules are enabled for the pair. If any one is missing, the analyzer simply does not appear on the QC Dashboard.

Known defects on version 3.2.2.0

  • Saving the Edit Control Lot page fails (Failed to save control lot), so lots cannot be edited or set Inactive after creation.
  • Rule Configuration may show a different test name from the one chosen on the control lot.
