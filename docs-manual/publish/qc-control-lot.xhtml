Receive and activate a control lot

At a glance

PurposeRegister a new lot of control material so that OpenELIS can evaluate the control results an analyzer sends for it against Westgard rules.
You'll end up withA control lot with status Active in the Control Lots list, tied to one analyzer and one test, with its statistics method set. Saving the lot also creates the Westgard rule set for that analyzer and test pair.
Who does thisThe person who receives and puts new control material into service — typically a bench supervisor or quality officer. Access is set by user permissions and can be configured by your administrator.
Before you startThe control material insert (lot number, level, expiry date and, for the Manufacturer Fixed method, the assigned mean and standard deviation for the test). The analyzer must already exist in the Analyzers List.
WhereMain menu → Analyzers → Quality Control → Control Lots

Every time a new lot of control material arrives you register it here, one lot per analyzer-and-test pair. The lot carries the mean and standard deviation that the Westgard rule evaluation uses, so it must exist and be Active before control results for that lot can be judged.

Step-by-step

Step 1. Open Control Lots. The list shows each lot's Lot Number, Control Material, Manufacturer, Control Level, Status, Calculation Method and Expiration Date, with a Status filter above it. Choose New Control Lot.

{{IMG:01-control-lots-empty.png}}

Figure 1. The Control Lots list before any lot has been registered, with the New Control Lot action.

Step 2. On the New Control Lot form, enter the Lot Number and Control Material exactly as printed on the vial or insert, choose the Control Level (Low, Normal or High), and set the Expiration Date using the calendar picker. Choose the Analyzer; the Test list is disabled until an analyzer is selected. Leave Status on Active.

{{IMG:02-new-control-lot-filled.png}}

Figure 2. The New Control Lot form completed for a Low-level hematology control on the analyzer's Hb test, with Status set to Active.

Step 3. In the Statistics Configuration panel choose Configure. The default Calculation Method is Manufacturer Fixed, and Save is disabled until a Mean and Standard Deviation are entered. Pick one of the three methods:

  • Manufacturer Fixed — use the mean and SD printed on the manufacturer's insert. Enter Mean and Standard Deviation. This is the usual choice when the insert gives assayed values for your test and method.
  • Rolling Window — recalculate the mean and SD from the most recent N results. Set the Window Size (default 20). Use this when you prefer limits that follow the instrument's own performance over time.
  • Initial Runs — calculate the mean and SD once from the first N establishment runs, then hold them fixed. Set Runs Required (default 20). Use this to establish laboratory-specific limits for a lot before it goes into routine evaluation.

Choose Save in the dialog to keep the method.

{{IMG:03-statistics-manufacturer-fixed.png}}

Figure 3. Statistics Configuration with Manufacturer Fixed selected and the insert's Mean and Standard Deviation entered.

{{IMG:04-statistics-rolling-window.png}}

Figure 4. The same dialog with Rolling Window selected, showing the Window Size control.

Step 4. Confirm the Statistics Configuration panel now shows the Calculation Method, Mean and Standard Deviation you set, then choose Save on the form.

{{IMG:05-statistics-configured.png}}

Figure 5. The Statistics Configuration panel after the dialog is saved, and the form's Save action.

Step 5. The list reopens with the new lot shown as Active, with its Calculation Method and Expiration Date. Saving the lot also creates a Westgard rule set for the analyzer and test — see Set up QC for an instrument to review it.

{{IMG:06-control-lots-list.png}}

Figure 6. The Control Lots list with the new lot registered and Active.

Step 6. Use the Status filter to show All Statuses, Establishment, Active or Expired lots.

{{IMG:07-status-filter.png}}

Figure 7. The Status filter on the Control Lots list.

Field reference

Lot NumberThe manufacturer's lot identifier.
Control MaterialThe product name of the control. Shown in the list as Control Material. The list's separate Manufacturer column is not set from this form and shows “-”.
Control LevelLow, Normal or High. Register one lot per level you run.
Expiration DateFrom the insert; set it with the calendar picker.
AnalyzerThe analyzer this lot is run on. Only analyzers already in the Analyzers List are offered.
TestThe test whose control results this lot covers; enabled once an analyzer is chosen. The list offers every test in the catalog, not only tests mapped to the analyzer, so choose carefully.
StatusActive / Inactive toggle. New lots default to Active. The list's Status filter has no Inactive value; its values are Establishment, Active and Expired.
Statistics ConfigurationCalculation Method (Manufacturer Fixed, Rolling Window, Initial Runs) with the method's Mean and Standard Deviation, Window Size, or Runs Required.

Tips

  • With Manufacturer Fixed, saving the form without configuring a Mean and Standard Deviation fails with the message Error — Failed to save control lot. Open Configure and enter both values first.
  • If the Save button in the Statistics Configuration dialog is greyed out, a required value for the chosen method is missing.
  • Known defect (3.2.2.0): saving the Edit Control Lot page fails with Error — Failed to save control lot, even when nothing has been changed. Existing lots therefore cannot currently be edited or set to Inactive from this screen. If a lot was registered with a wrong value, register a corrected lot rather than editing the existing one.
  • Known defect (3.2.2.0): the Rule Configuration page may show a different test name for the pair than the one you selected here (for example VGM after choosing Hb). The rule set still belongs to the lot you saved.
  • The page title and breadcrumb read Analyzers > Quality Control Dashboard > Control Lots: the middle segment says Quality Control Dashboard although the Main menu entry is Quality Control. You are on the Control Lots screen.

{{IMG:08-edit-control-lot-error.png}}

Figure 8. The Edit Control Lot page after switching Status to Inactive and choosing Save, showing the error notification described above. The same error appears when Save is chosen with no changes.

Not yet available

  • Control results cannot be entered by hand on these screens; they arrive only through an analyzer's electronic connection.
  • There is no separate Deactivate or Recalculate action in the row menu — the row menu offers Edit only.
  • Because Edit cannot be saved on this version, what a lot switched to Inactive looks like in the list (it is expected to appear under Expired) could not be verified.
