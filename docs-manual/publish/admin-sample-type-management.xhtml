Admin — Sample Type Management

At a glance

PurposeCreate and manage the sample types (specimen and organism types) used across the laboratory, assign tests to them, and set their display order.
Who does thisAdministrators. Access is set by user permissions.
WhereMain menu → Admin → Test Management → Manage Sample Types.
ScopeThis is a shared, cross-domain registry. A sample type defined here is generic until domain work assigns it to a domain — it only appears in Environmental or Vector order entry once it has been set to that domain.

Domain assignment. Sample types are not Environmental or Vector on their own. A sample type becomes part of the Environmental or Vector workflow only after the domain configuration assigns it to that domain. Until then it is a generic sample type available to whichever domains it is assigned to.

Manage sample types

Step 1. Open Admin → Test Management → Manage Sample Types. The page offers three actions: Create New Sample Type, Set Sample Type Order, and Test Assignment.

{{IMG:01-manage-sample-types.png}}

Figure 1. Manage Sample Types, with its create, ordering, and test-assignment actions.

Step 2. To add a sample type, choose Create New Sample Type, enter the English and French names, and continue.

Step 3. Use Test Assignment to assign at least one test to the sample type. A new sample type stays inactive until at least one test is assigned to it. Use Set Sample Type Order to position it in the lists where it appears.

Tips

  • Because the registry is shared, the same screen manages clinical, environmental, and vector sample types — what makes a sample type appear in a given domain is the domain assignment, not this screen alone.
  • A sample type with no tests assigned remains inactive and will not appear for ordering.
