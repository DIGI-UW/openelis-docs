How-to · Reception and laboratory staff

Part of the clinical order pipeline: Enter Order → Prepare Samples → Sample check

Status: draft for review. New for the Order Entry v4 screens (OpenELIS 3.3.0), driven on testing.openelis-global.org on 7 October 2026. Sample check replaces the QA Review step for clinical orders. Environmental and vector orders still use Complete QA review.

At a glance

PurposeConfirm each sample is acceptable and release the order to the laboratory.
You'll end up withThe order released, with status Ready for testing, so results can be entered as they arrive.
Who does thisReception or laboratory staff. Access is set by user permissions and can be configured by your administrator.
Before you startAn order whose samples have been saved on Prepare Samples.
WhereSave and next on Prepare Samples, or Main menu → Order → Add Clinical Order → Sample check

When this step appears

Sample check is the third step when your laboratory uses intake acceptance for clinical samples. Acceptance enforcement is set per domain (Off, Optional or Mandatory); this page was captured with clinical acceptance set to Optional and no acceptance checklist configured.

With acceptance set to Off, the order is expected to finish at Prepare Samples with no Sample check step. This has not yet been verified on a live instance. Confirm before publishing.

Steps

  1. Open the order. Save and next on Prepare Samples lands here with the order loaded, and the page title is tagged Saved. The step bar shows Enter Order and Prepare Samples as Done and Sample check as Ready; the order card shows Samples prepared and 2/3 steps.

  2. Review intake acceptance for each sample. The Intake Acceptance table lists each sample with Lab #, Sample type, Transit and Eligibility (for example Accepted). The table's help text says to select a sample to complete its acceptance checklist. The panel below it shows the domain (Clinical), when the sample was collected and received, the transit time, and the active list. Transit is shown for reference only and does not grade anything automatically. If no checklist is configured, the panel says No acceptance checklist is configured for this domain.

    {{IMG:01-intake-acceptance.png}}

    Figure 1. Sample check: the Intake Acceptance table with one Serum sample, Accepted, and its checklist panel.

  3. Check the summaries. Patient Information (name, date of birth, sex), Sample Summary (each sample type with its tests) and Order Details are collapsible sections below.

    {{IMG:01b-summary-footer.png}}

    Figure 2. The summaries and the footer, with Release for testing.

  4. Release the order. Press Release for testing. The step bar shows all three steps Done, the order becomes Ready for testing at 3/3 steps, and a completion panel reads Order … complete. Order entry is finished. Results can be entered as they arrive. Back to orders opens the Order Dashboard, which shows the same message at the top. Start New Order is offered below it.

    {{IMG:02-released.png}}

    Figure 3. The order released for testing, with the completion panel.

The footer also offers Return to Prepare Samples, Save and exit, Discard, Back and Report NCE.

Tips

  • A released order shows Open rather than Continue and Cancel order on the Order Dashboard.
  • The Transit time is a reference figure. Judge a delayed sample against your own acceptance criteria.
