How-to · Reception and sample collection staff

Part of the clinical order pipeline: Enter Order → Prepare Samples → Sample check

Status: draft for review. Rewritten for the Order Entry v4 screens (OpenELIS 3.3.0) and driven on testing.openelis-global.org on 7 October 2026. Prepare Samples replaces the old Collect step and takes over labelling and storage from Label & Store. The earlier Collect version of this page is in this page's history.

At a glance

PurposeRecord each tube for an entered order: what it is, when and by whom it was collected, how it arrived, its labels and where it is stored.
You'll end up withThe order's samples saved with collection and receipt details, labels printed, and the order status Samples prepared.
Who does thisReception or sample collection staff. Access is set by user permissions and can be configured by your administrator.
Before you startAn order saved on Enter Order, and the tubes in hand.
WhereSave and next on Enter Order, or Main menu → Order → Add Clinical Order → Prepare Samples and scan the lab number

Steps

  1. Open the order. Save and next on Enter Order lands here with the order loaded. Otherwise scan or type the lab number in Scan barcode or enter lab number. The order card shows the lab number, the status (Entered), the patient, the samples with their test count, and the step counter.

  2. Check the Requested Tests table. Each ordered test is a row with its Compatible Sample Types (green tags) and its Sample Assignments, for example Serum (Sample 1). A Multi-Sample Collection Example under the table, headed When multiple sample types are needed, shows Plasma (Sample 1) + Plasma (Sample 2) = Creates separate tubes for each type.

    {{IMG:01-requested-tests.png}}

    Figure 1. Prepare Samples for a newly entered order: Enter Order is Done, and three Serum tests are assigned to Sample 1.

  3. Add tests if needed. Add Tests or Panels is for a test the clinician asked for after the order was entered, or one that only becomes appropriate with the specimen in hand. It is listed per sample type with that sample type's current test count (Serum with 3 on the reference order).

  4. Record consent if your site captures it. Informed Consent holds one checkbox, Patient has provided signed consent.

  5. Fill in each sample card. Under Samples, each tube has a card (Sample 1, Sample 2…) listing its Assigned Tests. Above the cards, Received by names the person receiving, with a Change link. On each card:

    • Sample Type, Quantity and Unit (mL, slides, tubes, uL).
    • Collection Method. Its list comes from your site's configuration and may offer only Select.
    • Collection Location (GPS), a collapsed panel marked Optional with an Expand link.
    • Collection Date (its help text says it defaults to today; correct it if the sample was collected earlier), Collection Time (filled with the current time on the reference site) and Collector.
    • Handling: the requirement for the tests on this tube (for example Required: No requirement), Arrived as (Not recorded, Room temperature, Refrigerated 2 to 8 °C, Frozen, On ice, Dry ice) and Measured temperature (°C).
    • Stored at, which read Not stored yet for a tube with no location.
    • Received at Lab: Received Date and Received Time, marked Auto-filled from server.

    Add Sample adds another tube, for example when more was drawn than expected or a different sample type is needed; print its labels from its card or the Labels section. Remove Sample on a card removes one.

    {{IMG:02-sample-card.png}}

    Figure 2. The Sample 1 card filled in: 5 mL of Serum, collector, arrival at room temperature, and the server-filled received date and time.

  6. Set and print labels. The Labels section has an Order Labels table (one Order row, column Order Label) and a Sample Labels table with one row per tube (for example DEV01260000000000099-1 Serum, column Specimen Label). Each quantity starts at the label preset's default, tagged Preset default, and can be changed with the minus and plus buttons. Total labels adds them up.

    Before the first save the total is tagged Prints after save. Once the samples are saved, Print Labels on a sample card and Print all labels each open the labels as a PDF in a new browser tab, ready to print. Each table row also has its own printer icon under Print Labels.

    {{IMG:03-labels.png}}

    Figure 3. Order and sample label quantities from the presets, with Print all labels.

  7. Store the tubes, or skip storage. Under Location, an Unassigned Samples notice lists tubes with no location. For each tube, search for a storage location (type 2 or more characters), or pick it level by level: Room, Device, Shelf, Rack, Box and Position (optional). Condition Notes records anything about storage conditions. Tick Skip storage for unassigned samples when the tubes go straight to the bench.

    Storage is not required to continue: Save and next succeeded with no location chosen and Skip storage unticked.

    {{IMG:04-location.png}}

    Figure 4. The Location section for one unassigned Serum tube.

  8. Save. Save and next saves the samples and opens Sample check; Prepare Samples shows as Done and the order status becomes Samples prepared. Save and exit, Discard and Back are also in the footer, with Report NCE below Back for reporting a non-conforming event on this order.

    Every sample must carry at least one test before you can continue. A sample with none is listed under To continue to Sample check, for example DEV01260000000000100-1 Whole Blood has no tests. Add them on Enter Order or remove the sample, with Save and next disabled and Save and exit still enabled.

    {{IMG:05-refer-footer.png}}

    Figure 5. The foot of Prepare Samples: Refer Out / Subcontract, Back, Report NCE, Discard, Save and exit and Save and next.

Tips

  • An order can leave Enter Order with a sample type and no tests, but it cannot leave Prepare Samples that way. Add the tests, or remove the empty sample.
  • Labels print only for saved samples. On a new order, save first, then print from the sample card or with Print all labels.
  • If your site has no storage rooms set up, the Room list is empty. Storage locations are managed under Storage Management.

Not yet available

  • Refer Out / Subcontract from this step. The section is on the screen but, on the reference site, said No samples available for referral even after the samples were saved. Referring one or several tubes from Prepare Samples is in development (OGC-1423).
  • Proposed tubes from the test catalog's container types, and body sites for swabs.
