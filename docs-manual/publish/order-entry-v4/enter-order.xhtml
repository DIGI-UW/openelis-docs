How-to · Reception staff

Part of the clinical order pipeline: Enter Order → Prepare Samples → Sample check

Status: draft for review. Rewritten for the Order Entry v4 screens (OpenELIS 3.3.0) and driven end to end on testing.openelis-global.org on 7 October 2026. The earlier four-stage version of this page (Enter Order → Collect → Label & Store → QA Review) is in this page's history.

At a glance

PurposeRegister a clinical order: the patient, the requesting site and provider, and at least one sample type, with its tests if you know them.
You'll end up withA saved order with a lab number, status Entered, ready for Prepare Samples.
Who does thisReception staff. Access is set by user permissions and can be configured by your administrator.
Before you startThe request form: the patient's details or identifier, the requesting site and provider, and the specimen type.
WhereMain menu → Order → Add Clinical Order → Enter Order

Order entry now has three steps

A clinical order goes through Enter Order, Prepare Samples and Sample check. The step bar at the top of each screen shows where the order is: the step in hand shows what is left to do (for example 2 to do) or Ready, steps not reached read Not started, and finished steps read Done with the time. The card under the step bar shows the lab number, the order status and a step counter such as 1/3 steps.

Labelling and storage, which used to be a separate Label & Store step, are now part of Prepare Samples. The old QA Review step is now Sample check.

{{IMG:01-enter-order-top.png}}

Figure 1. The top of Enter Order: the step bar, the order card with its lab number and In Progress status, and the Lab Number field.

Before the form: what your site shows

Several fields on this screen are switched on or off per site, under Main menu → Admin → General Configurations → Order Entry Configuration. See the General Configurations reference. If a field described here is missing, or you see one that is not described, the cause is usually configuration. This page was captured with EQA, Program and payment tracking on.

Steps

  1. Check the lab number. A lab number is already in the field when the screen opens, with Generate Lab Number beside it. The Scan barcode or enter lab number box at the top is for finding an existing order.

  2. Set sample handling if it applies. Tick External quality assessment (EQA) sample for an EQA specimen. This order has no patient is shown greyed out on this screen.

  3. Find the patient. Under Patient, Search for Patient is open by default. Its fields are Patient Id, Previous Lab Number, Last Name, First Name, Date of Birth and Sex, and the help text says any combination works and partial matches are accepted. Search looks in OpenELIS. External Search queries the Client Registry and needs at least a name and a date of birth. Pick the patient with the radio button in the results.

    The patient then shows as a Selected card with name, date of birth, sex and ID, an Edit details link and a Clear link.

    {{IMG:02-patient-selected.png}}

    Figure 2. A patient found by last name and selected. The Selected card replaces the search form.

  4. Or register a new patient. If the search finds nobody, choose New Patient. National ID, Sex and Date of Birth are required. Patient ID / Clinic ID / UR number, Last Name, First Name, Primary phone and Email are optional; Age/Years, Months and Days fill in from the date of birth. Phone numbers must match the format shown under the field (on the reference site, xxxx-xxxx). Emergency Contact Info, Additional Information and Identification Documents are collapsible sections.

    Press Create patient. The screen confirms The new patient is created when the order is saved. Nothing is written until you save the order.

    {{IMG:03-new-patient.png}}

    Figure 3. The New Patient form filled in for a new patient.

  5. Identify the requesting site. Under Site Search, type at least two characters of the Site Name to search, and press Select on the right row. If the site is not on file and your site allows it, choose + Add new organization "…"; a New card confirms it will be created as a new organization when this order is saved. Set Priority (Routine, STAT (Urgent), ASAP or Timed). Department / Ward / Unit reads Select facility first and is disabled until then. Tick Remember this site and requester for my next order before a run of orders from one clinic.

    {{IMG:04-site-search.png}}

    Figure 4. Site Search with one match and its Select button.

  6. Identify the provider. Under Provider Search, enter a name or phone number and press Search, then Select the right row. The provider shows as a Selected card with Edit details and Clear. If nobody matches, + Add new provider "…" splits the name into First Name and Last Name and adds a Title list (Doctor, Professor, Sister and others); the provider is created when the order is saved.

    {{IMG:04b-provider.png}}

    Figure 5. A provider found and selected.

  7. Choose a program, if your site uses them. According to its help text, selecting a Program displays that program's own Additional Order Information fields below it.

  8. Add clinical information (optional). Provisional Diagnosis is a working diagnosis that guides test selection and is not recorded as a confirmed diagnosis. Payment Status (Normal cash, Normal insurance, Reduced cash or Reduced insurance payment), Order Date (pre-filled with today), Next Visit Date and Sampling Performed At complete the section.

  9. Add at least one sample type, and its tests if known. Choose a Sample Type. Its Order Panels and Order Tests lists then appear, with a filter box and a count of the tests available; ticked tests show as tags above the list. Add Sample adds another specimen; Remove Sample takes one away.

    A sample type is required before you can save. Tests are not required to save Enter Order, but every sample needs at least one test before the order can leave Prepare Samples.

    {{IMG:05-sample-tests.png}}

    Figure 6. Serum chosen as Sample 1, with Creatinine, GPT/ALAT and GOT/ASAT ticked.

  10. Save. Until the order has what it needs, a To continue to Prepare Samples list above the buttons names what is missing (Select or create the patient, Add at least one sample type), Save and exit and Save and next are disabled, and the footer says how many items are needed. When the list is empty:

    • Save and next saves the order and opens Prepare Samples. Enter Order then shows as Done and the order status becomes Entered.
    • Save and exit saves the order and returns to the Order Dashboard with the order highlighted.
    • Discard is also offered, in red, to the left of the save buttons.

    {{IMG:06-to-continue.png}}

    Figure 7. The foot of Enter Order before a sample type is chosen: one item is needed, and Save and exit and Save and next are disabled.

Attachments takes up to 5 files, 10 MB each, as PDF, JPG, PNG or TIFF. On a new order the section says Save the order to add attachments.

Continue or cancel an order from the Order Dashboard

Main menu → Order → Add Clinical Order → Dashboard lists clinical orders with Lab Number, Patient, Facility, Priority, Status, Progress, Last Updated and Action. Above the table are a lab number search, a status filter, a priority filter and a From / To date range, with New Order at the top right.

  • Unfinished orders carry Continue and Cancel order in the Action column; orders that are ready for testing or cancelled carry Open.
  • Cancel order opens a confirmation: Its tests are cancelled and its samples are voided. Nothing is deleted. Choose a Reason for cancelling (Registered in the wrong domain, Duplicate order, Request withdrawn or Other); the Cancel order button stays disabled until you do. Stay closes the dialog without cancelling.
  • A cancelled order leaves the default All Statuses view. Choose Cancelled in the status filter to see it.
  • Scanning or typing a lab number into the dashboard's Scan barcode or enter lab number opens that order. An order that is ready for testing opens on Enter Order marked This order is in read-only mode, with an Edit button.

{{IMG:07-cancel-order.png}}

Figure 8. Cancelling an order from the dashboard, with Duplicate order chosen as the reason.

Order statuses on the dashboard rows are Entered, Samples prepared, Ready for testing and Cancelled. The status filter uses different names: In Progress, Awaiting sample check, Completed, Has referred tests, Referred Out and Cancelled.

Tips

  • The Sample section's help text says sample and test selection is optional at this step. In practice the order cannot be saved without a sample type, and it cannot leave Prepare Samples while any sample has no tests (that step's message says to add them on Enter Order or remove the sample).
  • Opening Enter Order uses up a lab number even if you leave without saving. On the reference site the number issued to an abandoned screen was skipped, and no order for it appeared on the dashboard.
  • Field labels and available fields vary by site. Check Order Entry Configuration before concluding the manual is wrong.
  • The Order Date field and the Date of Birth field can show dates in different orders (month first and day first) on the same screen: on the reference site Order Date read 10/07/2026 for 7 October while Date of Birth asked for dd/mm/yyyy. Read the placeholder before typing.

Not yet available

  • A warning about possible duplicate patients before a new one is created, and a Handling group on this screen. Both are in development (OGC-1424).
  • A record of lab numbers issued but never used.
