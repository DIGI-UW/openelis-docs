Overview

The Items page is the inventory board. Its subtitle reads What you have and what to reorder. Expand a row to see its lots and where they are. Each row is one kind of item, with how much is on hand, how its use is trending, when it is projected to run out, when it must be ordered by, its status and when it was last counted. A banner at the top names the items to reorder now. Tags group items (for example by laboratory section or by kind of item) so each team can filter the board to its own stock.

Step 1: Filter the board to your stock

Go to Main menu → Inventory → Items. Use the controls above the list to narrow it:

  • Search by item name, code, tag or lot number.
  • Filter by Status: All, Reorder now, Reorder soon, Adequate or Building data.
  • Filter by Location: where the stock is stored.
  • Filter by Tags: pick one or more tags. Each chosen tag appears under the filters with an ×, and Clear tags removes them all.
  • Show deactivated adds items that have been deactivated.

{{IMG:01-board-filtered.png}}

Figure 1. The Items board filtered to the tag Central laboratory, with the action buttons above the list and each item's code and tags under its name.

Read each row as follows:

  • On hand: the quantity in stock, in the item's units.
  • Usage trend and Runs out: projected from recorded use. Until enough use has been recorded, Runs out reads Too few days of use to project a run-out date, or Out of stock when nothing is left.
  • Order by: the date to place an order, with the lead time underneath, for example 30d (set) when a lead time was entered on the item, or 30d with a note to set it when none was entered and the default is used.
  • Status: Reorder now, Reorder soon, Adequate or Building data (not enough history yet). On order is added once the item has been marked as ordered.
  • Last count: the date of the last physical count, or Never counted.

Step 2: Check an item's lots

Press the arrow at the start of a row. The expanded row lists the item's lots with Lot Number, Expiration Date, Current Quantity, Status, QC Status, Storage Location and Flag. The lot to use next is flagged Use first. Under the lots, the row shows the median daily use over the last 30 days and the quantity by location.

Step 3: Act on an item

The menu at the end of an item row has Receive stock, Record Usage, Edit item details and Deactivate item.

Figure 4. The item menu for Bioline Malaria Ag P.f/Pan rapid test: Receive stock, Record Usage, Edit item details and Deactivate item.

Step 4: Define a new item

Press New item. The dialog notes This defines a kind of item. To add more of one that already exists, use Receive stock. Enter the Item Name and, as needed:

  • Code: leave blank to have one generated from the name.
  • Tags: type to find a tag or add a new one. An item can carry more than one.
  • Category, Manufacturer, Catalog number and Product barcode (UPC or GTIN), the barcode that is the same on every box of the product.
  • Units, for example mL, tests or kits.
  • Track lots and expiry: turn on for anything received in batches with an expiry date; leave off for consumables counted as a single pool.
  • Low Stock Threshold, Lead time (days) (leave blank to have it learned from your deliveries), Warn this many days before expiry, Stability After Opening (days), Storage Requirements, Compatible Analysers and Tests Per Kit.

Press Save.

{{IMG:05-new-item-dialog.png}}

Figure 5. New item filled in for Sodium hypochlorite 5% solution: category Disinfectants, manufacturer Jik, units litres, lots not tracked.

Step 5: Review reorder suggestions and mark items as ordered

Press Reorder suggestions (the number in brackets is how many items it lists), or Review and mark as ordered in the banner. The dialog lists items at or below their threshold, or projected to reach it before a new order could arrive, with On hand, Low Stock Threshold, Order by and Status. Tick the items you have ordered, add a Note (for example the requisition or PO reference) and an Expected date, and mark them as ordered. As the dialog says, this records that an order was placed; it does not place one. Export CSV downloads the list.

{{IMG:06-reorder-suggestions.png}}

Figure 6. Reorder suggestions: items below their threshold, two of them already On order, with the Note and Expected date fields and Export CSV.

Step 6: Count stock

Press Count mode. Each lot-tracked row gets a count box showing the quantity on hand (of 340 tests); items with nothing in stock read Nothing here to count. A banner explains Counting everywhere. Filter by location to count one shelf at a time. Only what you type is committed. Type the quantity you count. The difference from the recorded quantity appears beside it, and the banner counts the lots you have entered. Press Confirm count to commit the counts, or Cancel to leave count mode without changes.

{{IMG:07-count-mode.png}}

Figure 7. Count mode: 338 typed for Determine HIV-1/2 rapid test against 340 on record, shown as -2, and the banner reading 1 lot counted.

Step 7: Import items from a file

Press Import items. The dialog explains that a CSV file can define many items at once, that the preview saves nothing, and that re-importing a corrected file updates the same items rather than adding them again. Use Download the template for the column layout, then Add a CSV file and press Preview. What this file would do counts the lines that are new, updated, unchanged and skipped, and lists each line with its outcome and, for a skipped line, the reason. Press Apply to write the changes.

{{IMG:08-import-preview.png}}

Figure 8. The import preview for lab-consumables.csv: one new item and one unchanged item, nothing skipped.

Step 8: Record usage

Press Log usage (or Record Usage on an item's menu). Choose the Item Name and enter the Quantity used. The dialog shows how much is on hand and that lots are drawn earliest-expiry first. Press Record Usage. Recorded use feeds the run-out projection; to correct a count, use Adjust Quantity on the lot instead.

{{IMG:09-log-usage.png}}

Figure 9. Log usage for Determine HIV-1/2 rapid test: 20 tests used, with 340 tests on hand.

Tips

  • Enter a lead time on each item. Until you do, Order by uses a default of 30 days and says so.
  • Tag items by section (for example TB laboratory) and by kind (for example Rapid tests). The tag filter, the reports and the import file all use the same tags.
  • Count one shelf at a time by filtering by location before you press Count mode.
  • Usage is drawn from lots whose QC has passed. When the only lots of an item are still awaiting QC, recording usage was refused on the test server; set the lot's QC status first with Update QC Status.
  • Known issue: the Reorder now banner and the Reorder suggestions list ignore the tag filter, so they also list items outside the tags you picked (Figures 4 and 6).
  • Known issue: on the test server the expiry date shown for a lot on the board was one day earlier than the date entered when the lot was received.
  • The figures were captured with British English labels (for example Compatible Analysers). Your screens may use American spelling.
