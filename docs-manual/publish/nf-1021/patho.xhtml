Overview

On a pathology case, each cassette and each slide is now its own row. The identifier is assigned when you save, and each slide records the cassette it was cut from.

Step 1: Add cassettes at Grossing

Open the case (Main menu → Pathology, then the case) and expand 2. Grossing. Enter the Gross Exam, then press Add cassette once for each cassette. Each new row reads Assigned on save with a Cassette tag, a Location field and Remove. Print all cassette labels is not available until the cassettes are saved.

{{IMG:08-path-cassettes-unsaved.png}}

Figure 1. Grossing with a gross description and two new cassettes reading Assigned on save; the Case summary still shows 0 cassettes.

Step 2: Save to assign the identifiers

Press Save draft at the foot of the case. Each cassette gets a block code and a barcode, for example A1 DEV01260000000001252.A1 and A2 DEV01260000000001252.A2. Remove becomes Deactivate, Print all cassette labels becomes available, Grossing is tagged Complete, and the Case summary counts the cassettes.

{{IMG:09-path-cassettes-saved.png}}

Figure 2. After Save draft: cassettes A1 and A2 with their barcodes and Deactivate links, Print all cassette labels available, and Cassettes 2 in the Case summary.

Step 3: Add slides at Microtomy

Move the case to Microtomy with the Status control at the foot of the case, which notes Stage transitions arrive in a later release. Set the stage here for now., and press Save draft. Expand 6. Microtomy and press Add slide for each slide. Each new slide row reads Assigned on save and has Cut from block (a list of the case's saved cassettes, here A1 and A2), Location, Upload file and Remove. Choose the block for every slide; a slide saved without one is refused with Pick the block this slide was cut from.

{{IMG:10-path-slides-unsaved.png}}

Figure 3. Microtomy with two new slides, cut from blocks A1 and A2, still reading Assigned on save.

Press Save draft. Each slide gets its own barcode under its block, for example DEV01260000000001252.A1.1 and DEV01260000000001252.A2.1, the section is tagged 2 slides, and the Case summary shows Slides 2.

{{IMG:11-path-slides-saved.png}}

Figure 4. After Save draft: slides DEV01260000000001252.A1.1 and A2.1, each showing the block it was cut from, with Deactivate and Print all slide labels.

Tips: Moving the case through Decalcification, Processing and Embedding showed the message OpenELIS does not record work at this stage yet. The case can still be moved through it. Slide numbers restart in each block, so the first slide from A1 and the first from A2 are both numbered 1. Printing cassette and slide labels and uploading a slide file have not yet been verified on a live instance.

Field reference

Field or controlWhereWhat it does
Add cassettePathology case, GrossingAdds a cassette row; the block code and barcode are assigned on save.
Add slide, Cut from blockPathology case, MicrotomyAdds a slide row; the block it was cut from must be chosen before saving.
DeactivateSaved cassette or slide rowShown in place of Remove once the row has an identifier. Not driven.
Status, Save draftFoot of the pathology caseSets the case stage by hand and saves the case.

Not yet available

  • Automatic stage transitions on the pathology case; the stage is set by hand for now.
  • Recording work at the Decalcification, Processing and Embedding stages.
