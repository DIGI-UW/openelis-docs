Part A: Add tests to an existing order

When you add tests to a sample that is already on an order, you can now search for a test, see your choices as tags, and add a whole panel at once.

Step 1: Open the order and go to Available Tests

Go to Main menu → Order → Edit Order. The page is titled Modify Order. Under Search By Accession Number, enter the lab number and press Submit. The order opens at Test Request with the steps Program Selection, Add Sample and Add Order. Press Next to reach the sample step, which shows Current Tests and, below it, Available Tests for each sample (for example DEV01260000000001250-1 (Serum)).

Step 2: Search for a test

Under Search through the available tests, type part of the test name in Choose Available Test. Matching tests are listed under the box; pick one to add it. Tests already on the sample are not offered (here Total cholesterol is not in the list).

{{IMG:01-mo-search.png}}

Figure 1. Available Tests for a Serum sample: "chol" typed in the test search, with HDL cholesterol offered below the box, above the full list of test checkboxes.

Step 3: Add a panel

Under Order Panels, tick a panel, or search for one in Choose Available panel. The panel appears as a green tag under Order Panels, and its tests are ticked in the test list and shown as tags above it. Each tag has an × to remove it.

{{IMG:02-mo-panel.png}}

Figure 2. The Bilan Biochimique panel ticked: the panel tag, and tags for Amylase, Creatinine, GOT/ASAT, GPT/ALAT, HDL cholesterol and Triglicerides, which are also ticked in the list.

Step 4: Save

Press Next to go to Add Order, then Submit. The page shows Successfully saved with a PRINT LABELS panel for the order (quantity, Print, a link to print later) and Done.

{{IMG:03-mo-saved.png}}

Figure 3. Successfully saved, with the Print Labels panel for DEV01260000000001250 and the Done button.

Opening the order again lists the added tests under Current Tests.

{{IMG:04-mo-current-tests.png}}

Figure 4. Current Tests after saving: 7 items, with GPT/ALAT, GOT/ASAT, Creatinine, Amylase and Total cholesterol on the first page.

Tips: The Current Tests table is wider than its panel at a 1440-pixel-wide window, so its last column (Cancel Test) is cut off; scroll the table sideways to reach it. When a test chosen by search was also in a panel that was ticked and then unticked, the test's tag was removed along with the panel's tests; check the tags before saving. This was seen once and has not been confirmed.

Part B: The requesting provider can be optional

A new setting controls whether the requesting provider must be entered on a clinical order.

Step 5: Check the setting

In Admin, open General Configurations → Order Entry Configuration. The row requesterRequired reads If true, Search Requester and Requester First/Last Name are required on Order Entry. Default false makes them optional. On the instance documented here its value is false. To change it, select the row and press Modify.

{{IMG:05-oec-config.png}}

Figure 5. Order Entry Configuration with the requesterRequired row set to false.

Step 6: Enter an order without a provider

On Main menu → Order → Add Clinical Order → Enter Order, the Requester section has Site Search and Provider Search. Site Name is marked with a red asterisk and its help text reads Type at least 2 characters to auto-search. Required for routing results back to the requesting site. None of the provider fields (Provider Name, Provider Phone, First Name, Last Name, Phone, Provider Email) is marked as required.

{{IMG:06-oec-requester.png}}

Figure 6. The Requester section of Enter Order: Site Name marked required, and the Provider Search fields with no required markers.

With requesterRequired set to false, an order with a patient, a sample type and a test but no provider can be saved: Save and exit and Save and next are both enabled, and Save and next opens Prepare Samples.

{{IMG:07-oec-footer.png}}

Figure 7. The foot of Enter Order with Total cholesterol ticked on a Serum sample and no provider entered: Save and exit and Save and next are both enabled.

Known issue: although Site Name is marked required, on the instance documented here an order with no site was also accepted. Save and next saved such an order and opened Prepare Samples, and Save and exit saved one that the Order Dashboard lists with --- in the Facility column. Always enter the site, because results are routed back to it.
