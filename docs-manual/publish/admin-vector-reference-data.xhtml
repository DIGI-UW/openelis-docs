Admin — Vector Surveillance Reference Data

At a glance

PurposeMaintain the reference data the Vector Surveillance workflow depends on: the species list (used for identification), trap types (offered at order entry), sampling sites (the collection locations), and the organism sample types.
Who does thisAdministrators. Access is set by user permissions.
WhereMain menu → Admin → Vector Surveillance (Species, Trap Types, Sampling Sites).
Used byThe Vector Surveillance order-entry and identification screens.

Add a species

Step 1. Open Admin → Vector Surveillance → Species. The list shows Genus, Species, Subspecies, Sample type, Pathogens of Interest, and Status, with sample-type filter chips.

{{IMG:01-species.png}}

Figure 1. The Species reference list with its sample-type filters.

Step 2. Choose Add species and complete Genus, Species, the Sample type, and the optional Subspecies, Pathogen category, and Lifecycle category, then Save species. The species becomes selectable in the Vector Identification Identify form for matching sample types.

Add a trap type

Step 3. Open Admin → Vector Surveillance → Trap Types. The list has a name/description search, a per-row Edit, and an active/inactive toggle.

{{IMG:02-trap-types.png}}

Figure 2. The Trap Types reference list.

Step 4. Choose Add trap type, enter a Name and optional Description, tick the associated sample types, and Save trap. The trap type then appears as a Trap Type choice on vector order entry for those sample types.

Manage sampling sites

Step 5. Open Admin → Vector Surveillance → Sampling Sites. Sampling sites are the collection locations selected on an order.

{{IMG:03-sampling-sites.png}}

Figure 3. The Sampling Sites reference list.

Sample types

Sample types are not maintained on this page. They live in their own shared registry — see Admin — Sample Type Management. A sample type becomes available to the Vector workflow only once the domain assignment sets it to the Vector domain; create or edit sample types there.

Tips

  • Species, trap types, and sampling sites added here flow straight into the vector order-entry and identification screens.
  • Use the active/inactive toggle to retire a trap type without deleting its history.
