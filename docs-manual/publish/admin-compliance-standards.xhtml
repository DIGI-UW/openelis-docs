Admin — Compliance Standards & Holding-Time Configuration

At a glance

PurposeDefine the regulatory compliance standards that environmental results are judged against, and the SOP maximum holding times that trigger expired-holding-time warnings at result entry.
Who does thisAdministrators. Access is set by user permissions.
WhereMain menu → Admin → Test Management — Compliance Standards Administration and Modify tests.
Used byThe Environmental Surveillance order-entry and results screens.

Step 1. Open Admin → Test Management. The Test Management menu groups the test-configuration tools, including Compliance Standards Administration and Modify tests.

{{IMG:01-test-management-menu.png}}

Figure 1. The Test Management configuration menu.

Define a compliance standard

Step 2. Open Compliance Standards Administration. The list shows each standard's Name, Issuing Body, Regulation Number, Version, Effective Date, Status, Applicable Sample Types, Groups, and Tests, with filters for Status, Region, and Sample Type.

{{IMG:03-standards-list.png}}

Figure 2. The Compliance Standards Administration list, with its filters and the Add Standard action.

Step 3. Choose Add Standard and enter the header (Standard Name, Issuing Body, Regulation Number, Version). Set the Effective Date using the date-picker calendar. Under Applicable Sample Types, choose a sample type and choose Add (repeat per type), then Save.

Note — save gate. Save becomes available only after both an Effective Date is set via the calendar and at least one Applicable Sample Type is added.

Step 4. Define the standard's Parameter Groups & Linked Tests, setting each test's limit type. These limits drive the PASS / FAIL evaluation users see at result entry.

Set a test's SOP maximum holding time

Step 5. Open Modify tests, choose a Sample Type, and open the test. On the Configuration tab, step through to the QC Acceptance Thresholds section and set SOP Max Holding Time (minutes), then save. This drives the expired-holding-time warning shown at result entry.

{{IMG:02-modify-tests.png}}

Figure 3. Modify tests — the test configuration where the SOP maximum holding time is set.

Tips

  • The compliance evaluation is numeric-only and is computed on the server; it appears to users after they save and reload the results screen.
  • Set the Effective Date with the calendar control — a typed value alone may not enable Save.
