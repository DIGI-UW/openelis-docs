At a glance

Purpose

Create and maintain the laboratory’s lab units (lab sections): their domain, whether they are active, which tests belong to them, and the order they appear in.

You’ll end up with

A lab unit that appears in the lab unit menus and dropdowns, in the position you chose, with the tests you assigned to it.

Who does this

Administrators.

Before you start

Know the domain the unit belongs to (Clinical, Environmental or Vector). Tests you want to assign must already exist in the test catalogue and be active.

Where

Main menu → Admin → Test Catalogue Management → Lab Units Editor.

Overview

The Lab Units Editor opens on a list of every lab unit with its domain, status and test count. Each unit is edited in three sections chosen from the left navigation: Basic Info, Assigned Tests and Display Order. A test belongs to exactly one lab unit, so assigning a test here moves it out of the unit it was in.

Step 1: Open the list

Open Main menu → Admin → Test Catalogue Management → Lab Units Editor. The page is titled Lab Unit Management and reads Configure lab units (lab sections), domain classification, test assignments, and display order. Under the title, Total: 35 lab units gives the count for the instance, and the tags at the top right count the units per domain (24 Clinical, 8 Environmental, 3 Vector on the build used here). The table lists Name (with the unit’s description beneath it), Domain, Status, Tests and Actions, twenty rows per page.

The Lab Unit Management list with the domain counters, the search box, the two filters and Add Lab Unit.

Step 2: Find a lab unit

Type in Search lab units...: the list filters as you type. Typing Hema left three rows (Hematology and two Hemato-Immunology units) and the counter changed to Showing 3 of 35 lab units. Narrow further with All domains and All statuses (Active or Inactive). Click Edit on a row to open the unit’s Basic Info.

The list filtered as you type: three units match "Hema".

Step 3: Add a lab unit

  1. Click Add Lab Unit. The form is headed Add New Lab Unit.

  2. Enter Name (English), the one required name; the helper reads Enter a unique name for this lab unit (e.g., "Hematology", "Microbiology"). The other name fields, one per language the instance has enabled (Français, Español, Indonesia, French Madagascar and English (US) here), are optional.

  3. Choose the Domain: Clinical, Environmental or Vector. The helper explains that it determines which order entry and sample collection fields apply to orders routed to this lab unit.

  4. Click Create Lab Unit. The button stays disabled until the English name and a domain are set. The name is checked when you click: a name already in use is refused with This lab unit name already exists, and a name over twenty characters with Name must be 20 characters or less, both shown under the field.

The Add New Lab Unit form with one name field per enabled language and the domain choice.

A duplicate name refused when Create Lab Unit is clicked.

The new unit opens in its Basic Info section, headed Editing: <name> with a domain tag and an Inactive tag: a new lab unit is created inactive. Two more fields appear that the add form did not have: the Active switch and a Description (60 characters at most, prefilled with the name, described as a short internal description of this lab unit for lab staff reference).

The unit just created: inactive, with the Active switch and Description now available.

Step 4: Edit Basic Info

Change the names, the description or the Active switch and click Save. A green message Lab unit saved successfully. confirms the save and the tags in the header update.

Basic Info after a save, with the confirmation message.

Two changes ask for more care:

  • Changing the domain of an existing unit opens the dialog Change Lab Unit Domain?: Historical orders/results were evaluated against the prior domain's rules. New orders will use the new domain's rules. Cancel puts the previous domain back; Confirm keeps the new one for the next Save.

  • Switching a unit off that still has active tests shows a warning under the switch, for example 58 active tests are assigned to this lab unit. Deactivating hides it from ordering but keeps the assignments. The save is still allowed. In 3.3.0 the tests of an inactive unit are no longer offered in order entry (OGC-1207): with a Sputum test moved into an inactive unit, Enter Order listed only the Sputum tests of active units.

The confirmation asked for before a domain change.

The warning shown when Active is switched off on a unit that still has tests.

Step 5: Assign tests to the unit

Open Assigned Tests in the left navigation. The section counts the tests (63 tests assigned for Hematology) and lists them with their domain and status. Click Assign tests. The dialog Assign Tests to This Lab Unit explains: Tests belong to exactly one lab unit. Assigning a test here moves it out of its current lab unit (shown next to each test). Only active tests are offered. Search with Search tests..., tick the tests, and click Assign N tests, or Cancel.

After the assignment the message Tests assigned to this lab unit. appears, the table lists the test with its domain and status, and the count updates. In 3.3.0 an inactive unit stays inactive when it receives a test (OGC-1459): switch it on in Basic Info when it should be used. On 3.2.2.0 the unit became active at once, as in the figure below.

The Assign Tests dialog: each candidate shows the unit it currently belongs to.

After assigning one test on 3.2.2.0: the confirmation, the new count and the unit tagged Active. In 3.3.0 the unit stays Inactive.

Step 6: Move tests to another unit

In Assigned Tests, tick one or more rows; the Reassign selected (N) button becomes available. Click it. The Reassign Tests dialog asks for a Destination lab unit, lists the tests that will be moved, and warns: Reassignment takes effect immediately. New orders route to the destination lab unit; completed results keep their original data. Click Reassign N tests to confirm. The message Tests reassigned successfully. appears, the tests leave this unit’s list and belong to the destination. Inactive tests can be moved this way too.

Reassigning one test: the destination is chosen in the dialog.

After the reassignment: the confirmation and the emptied list.

Step 7: Set the display order

Open Display Order. The section reads Position this lab unit in the system-wide lab unit menus and dropdowns. Enter a position and save. The remaining lab units are renumbered automatically. Enter a Position and click Save. The message Display order saved appears and the table beneath shows the new sequence with the current unit marked Current: entering 2 moved the new unit to second place and shifted the others down. A newly created unit starts last (position 36 on a list of 35).

Display Order after saving position 2: the confirmation and the renumbered table.

Field reference

Field

Notes

Name (English)

Required and unique, 20 characters at most. The other language names are optional and fall back to the English name.

Domain

Clinical, Environmental or Vector. Required. Decides which order entry and sample collection fields apply to orders routed to the unit. Changing it later asks for a confirmation.

Active

Off for a new unit. Switched on automatically when a test is assigned. An inactive unit is hidden from ordering; its test assignments are kept.

Description

Internal note for lab staff, 60 characters at most. Shown under the name in the list.

Tests (list column)

Number of tests assigned to the unit.

Position (Display Order)

Position in the lab unit menus, counted from 1; the other units are renumbered around it.

Tips

  • The left navigation shows the section links greyed out until you open a unit; the caption reads Click a lab unit to edit its sections.

  • The navigation entry is called Lab Units Editor while the page title reads Lab Unit Management. They are the same screen.

  • Assign tests offers active tests only. To move an inactive test, open the unit it belongs to and use Reassign selected.

  • The Lab Unit field on a test’s Basic Info (Test Catalogue Editor) does not filter as you type; scroll the list to find the unit. The search box on this page does filter.

  • There is no delete. Retire a unit by switching Active off; move its tests first with Reassign selected if they should stay orderable.
