Part of: Test Catalog Management — workflow overview

How-to · Lab administrators

At a glance

Purpose

Set a test's domain, AMR surveillance flag, and status.

You'll end up with

The test classified and its status set.

Who does this

Lab administrators. Access is set by user permissions and can be configured by your administrator.

Before you start

The test exists in the catalog. To create one, see Admin — Add a test to the test catalogue.

Where

Main menu → Admin Management → Test Catalogue Management → Test Catalogue Editor → your test → Basic Info.

  1. Open the test and stay on Basic Info.

  2. Edit the Name, Code and Description if needed. The display name is translated — edit it in the Localization section.

  3. Set the Domain — Clinical, Environmental, or Vector. Choosing a different domain opens a Change test domain? confirmation dialog; click Confirm to apply it. (The change is not committed — and Save will not persist it — unless you confirm the dialog.)

  4. Set AMR surveillance test to Yes if results feed antimicrobial-resistance surveillance.

  5. Set the Culture workflow if this test is part of one.

  6. Toggle Active and Orderable as needed. A test that is not Active cannot be ordered, whatever the Orderable setting says.

  7. Click Save.

Tips

  • Labels differ between creating and editing. The create form says Test name and Test code; once saved, the same fields read Name and Code.

  • Culture workflow and Active appear only after the test has been saved. Neither is on the create form.
