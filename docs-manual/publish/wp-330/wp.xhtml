How-to · Bench staff and lab supervisors

At a glance

Purpose

List the tests waiting to be done for one lab unit, one test, one panel or one priority, and print that list as the day's work plan.

You'll end up with

A printed work plan (PDF) listing each lab number, its date of reception and the test to run.

Who does this

Bench staff and supervisors who share out the work. Access is set by user permissions and can be configured by your administrator.

Before you start

Samples must have been received and their tests not yet resulted. A work plan only lists tests still waiting for a result.

Where

Main menu → Workplan → By Test Type, By Panel, By Unit or By Priority

Step 1: Choose how to group the work

  1. Open Main menu → Workplan and choose the screen that matches how your bench is organised:

    • By Unit: every waiting test in one lab unit, such as Hematology. Use it to give a section its work for the day.

    • By Test Type: every waiting sample for one test, such as Creatinine (Serum). Use it when one person runs one test on a batch.

    • By Panel: every waiting test that belongs to one panel.

    • By Priority: every waiting test with one priority: Routine, ASAP, STAT, Timed or Future STAT. Use STAT at the start of a shift to see urgent work first.

  2. Pick a value in the list at the top of the screen (Unit Type, Test Type, Panel Type or Priority). The table fills in straight away; there is no search button.

Step 2: Read the list

  1. The line above the table gives Total Tests. The table lists each waiting test with its Accession Number, Test Name and Received Date, in lab number order. A red flag next to an accession number means the sample or order is nonconforming or the test has been rejected.

    {{IMG:01-by-unit.png}}

    Figure 1. Workplan By Unit for Hematology: six waiting tests, with one row ticked under Remove.

  2. Select an accession number to open the Results screen for that lab number, ready for entering results.

Step 3: Leave tests off the printed plan

  1. To give part of the list to someone else, tick Remove on the rows that should not be on this printed plan. The rows stay on the screen and Total Tests does not change; only the printout leaves them out. Print the remaining rows for a second person by ticking the other rows instead.

Step 4: Print the work plan

  1. Select Print Workplan (above or below the table). OpenELIS opens the work plan as a PDF in a new browser tab, where you can print or save it.

  2. The printout is headed Work plan: and the unit, test, panel or priority you chose, with the date, and lists Lab No, Date of reception and Name of test for every row you did not remove.

    {{IMG:02-printed.png}}

    Figure 2. The printed work plan for Hematology. The removed row (DEV01260000000000108) is not on it.

The other groupings

By Test Type, By Panel and By Priority work the same way. By Test Type shows one test only, so its table has no Test Name column.

Field reference

Control

What it does

Unit Type, Test Type, Panel Type, Priority

Chooses which waiting tests are listed. Only one value at a time.

Total Tests

How many waiting tests match. It counts removed rows too.

Remove

Leaves that row off the printed work plan. Nothing is changed on the order or the test.

Accession Number

Opens Results for that lab number.

Print Workplan

Opens the PDF work plan in a new tab.

Tips

  • Large units can list many tests; use the page controls under the table to move through them.

  • Work plans list tests that are still waiting for a result, so print a fresh one when you start a new batch.

Not covered on this page

Batch Workplan also appears under Main menu → Workplan in 3.3.0. It belongs to work that is still being built and is not documented yet.
