OpenELIS 3.3.0. In 3.3.0 the QA Review stage became Sample check. Clinical orders have their own version: see Complete the sample check for a clinical order. This page covers environmental and vector orders. Sites on earlier releases can use Complete QA review (before 3.3.0).

How-to · Reception and laboratory staff

At a glance

Purpose

Check each sample of an environmental or vector order against the acceptance checklist, accept it, and release the order for testing.

You'll end up with

Every sample accepted (or reported as nonconforming) and the order Ready for testing.

Who does this

Whoever receives samples at the laboratory. Access is set by user permissions and can be configured by your administrator.

Before you start

The order has been through Label and store, and you have the samples in front of you.

Where

Save & Next on Label & Store brings you here. From the Main menu: Order → Add Environmental Order → QA Review (the menu still uses the old name).

Step 1: Open the sample's checklist

  1. Intake Acceptance lists each sample with its Lab #, Sample type, Transit time and Eligibility (Pending until you accept it). Select a sample to open its checklist.

  2. The checklist header repeats the collection and receipt times and the transit time. Transit is shown for reference only; it does not grade anything.

Step 2: Answer the checklist

  1. For each item, choose Pass, Fail or N/A. The environmental list has six items: Container intact / undamaged, Label legible and matches request, Sample volume adequate, Cold chain maintained, Acceptable transit time / condition and Required paperwork present and complete. The items come from your site's Sample Acceptance Checklist.

    Sample check for a Surface Water sample: the Intake Acceptance list and the first checklist items answered Pass.

Step 3: Accept the sample, or report a problem

  1. When every item passes, select Accept sample. Its Eligibility in the list changes to Accepted.

  2. If a sample fails a check, use Report NCE to record a nonconforming event, or Resample to ask for a new sample. Neither was exercised for this page; see Report a non-conforming event.

    Below the checklist: Accept sample, Report NCE and Resample, the Sampling Site and Sample Summary panels, and Save and Submit

  3. Below the checklist, Sampling Site and Sample Summary show the site and each sample's tests, so you can check them against the containers. Order Details opens the rest of the order.

Step 4: Submit the order

  1. Select Submit. OpenELIS shows Order submitted successfully with the lab number, every stage on the progress bar is Done, and the order status becomes Ready for testing. Start New Order opens a blank Enter Order.

    The order submitted and ready for testing.

  2. Save keeps the checklist answers without submitting; Back returns to Label & Store.

Tips

  • Which checklist items appear, and how strictly they are enforced, is set per domain in Sample Acceptance Checklist.

  • Known issue (3.3.0-SNAPSHOT): after Submit the page heading reads QA Review while the breadcrumb and progress bar say Sample check, and the Main menu still lists QA Review. They are the same stage.
