Part of: Test Catalog Management: workflow overview

Reference · Test Catalog Management

Some editor sections display information owned elsewhere:

  • Analyzers: a read-only list of analyzers that can run this test. Mappings are maintained on the analyzer configuration screen, not here.

  • Reflex & Calc: read-only cross-links. Reflex rules are managed in Master Lists → Reflex Rules; calculated results show what this test "feeds into" and "is calculated by."

The following sections are present and routable but mostly show empty/configuration states at this build maturity:

  • Labels: add a label preset to suggest labels when the test is ordered; "Allow override at order entry."

  • Reagents: link reagents from inventory to track consumption per test.

  • Alerts: add a rule to notify recipients when results match a condition.
