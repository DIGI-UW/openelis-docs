How-to · Quality officers and bench supervisors

At a glance

Purpose

Register a new lot of control material so its results can be judged against the lot's target mean and standard deviation.

You'll end up with

An Active control lot in the Control Lots list, tied to one test and either an analyser or the bench, with its statistics method set.

Who does this

The person who puts new control material into service, typically a quality officer or bench supervisor. Access is set by user permissions and can be configured by your administrator.

Before you start

The control material in hand, with its lot number, level, expiry date and, for a fixed target, the manufacturer's mean and standard deviation from the package insert.

Where

Main menu → Quality Assurance → Statistical QC → QC Lot Management

Step 1: Start a new lot

  1. Open QC Lot Management and select New Control Lot. The New Control Lot form opens.

Step 2: Describe the lot

  1. Enter the Lot Number and the Control Material name as printed on the vial.

  2. Choose the Control Level: Low, Normal or High.

  3. Enter the Expiration Date (day/month/year).

  4. Choose the Analyser the lot is run on, or Bench / no analyzer (manual method) for a control run at the bench without an instrument. The help text under the field says the analyser is optional.

  5. Choose the Test the control is for. The list shows each test with its sample type, for example Glucose(Plasma).

  6. Leave Status switched to Active to put the lot into service now.

Step 3: Set the statistics method

  1. In Statistics Configuration, select Configure.

  2. Choose the Calculation Method: Manufacturer Fixed (use the manufacturer-provided mean and SD values), Rolling Window (recalculate from the most recent N results) or Initial Runs (calculate once from the first N establishment runs).

  3. For Manufacturer Fixed, enter the Mean and Standard Deviation under Manufacturer Values, then select Save in the dialog.

    {{IMG:01-configure-filled.png}}

    Figure 1. The Statistics Configuration dialog with Manufacturer Fixed chosen, mean 5.40 and SD 0.20.

  4. The values appear in the Statistics Configuration block on the form.

    {{IMG:02-new-lot-filled.png}}

    Figure 2. A new Normal-level chemistry control lot for Glucose(Plasma), run at the bench, ready to save.

Rolling Window and Initial Runs were not driven; the fields they show have not been verified on a live instance.

Step 4: Save

  1. Select Save. The Control Lots list opens with the new lot shown as Active.

    {{IMG:03-lot-list.png}}

    Figure 3. The new lot in the Control Lots list.

Field reference

Field

Notes

Lot Number

The lot number printed on the control material.

Control Material

The product name.

Control Level

Low, Normal or High. The list shows it in capitals (for example NORMAL).

Expiration Date

The lot's expiry date.

Analyser

Optional. An analyser, or Bench / no analyzer (manual method).

Test

The test the control is for.

Status

Active or inactive. The list can be filtered by status.

Calculation Method

Manufacturer Fixed, Rolling Window or Initial Runs, set with Configure.

Mean / Standard Deviation

The target values used with Manufacturer Fixed.

Tips

  • The Control Lots list has a Manufacturer column, but the form has no Manufacturer field, so the column shows a dash for lots created here.

  • Saving a bench lot does not add anything to Rule Configuration: after saving the lot above, Rule Configuration still showed No rule configurations found. Whether an analyser lot creates a rule set was not tested.

  • The breadcrumb reads Analysers › Quality Control Dashboard › Control Lots even when you arrive from Quality Assurance. This is a known inconsistency and does not mean you are on a different page.

Not yet documented

  • Editing, deactivating or retiring a lot (the row options menu was not opened).

  • Lots tied to an analyser.
