How-to · Administrators

At a glance

Purpose

View and set the site-level properties that identify your laboratory and control site-wide behavior.

You'll end up with

Updated site settings applied across OpenELIS (labels, prefixes, feature toggles).

Who does this

Administrators. Access is set by user permissions and can be configured by your administrator.

Before you start

The exact value to set. Some properties (external service URLs, credentials) should be coordinated with your technical team.

Where

Main menu → Admin → General Configurations → Site Information.

Site Information is a table of named properties, each with a Description and a Value. It covers site identity (accession number prefix, address and geographic-unit labels, banner heading), display options (24-hour clock, language change), and feature toggles (electronic signatures, external patient source).

Field reference (selected properties)

Property

Notes

Accession number prefix

Prefix for the site's lab numbers (e.g., DEV01); cannot be changed once samples exist.

electronicSignatureEnabled

Turns on 21 CFR Part 11 electronic signatures for result entry and validation.

esigSessionTimeoutMinutes

Inactivity timeout for the signing session (default 30).

bannerHeading

The application banner text; supports per-locale values (e.g., English / French).

allowLanguageChange

Lets users change the language at login.

Address / Geographic Unit labels

Rename the address lines and geographic units (e.g., Region, District) to local terms.

useExternalPatientSource

Import patient demographics from an external source.

TrainingInstallation

Marks the instance as a training installation — enables deletion of all patient and sample data. Use with extreme caution.

Notes

  • TrainingInstallation allows destructive deletion of all patient/sample data; only enable on a training instance.

  • Some values (service URLs, credentials) require technical coordination and may need a restart to take full effect.
