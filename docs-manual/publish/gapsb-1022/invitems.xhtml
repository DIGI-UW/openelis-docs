Overview

The Items page is the inventory board. Its subtitle reads What you have and what to reorder. Expand a row to see its lots and where they are. Each row is one kind of item, with how much is on hand, how its use is trending, when it is projected to run out, when it must be ordered by, its status and when it was last counted. A banner at the top names the items to reorder now. Tags group items (for example by laboratory section or by kind of item) so each team can filter the board to its own stock.

Step 1: Filter the board to your stock

Go to Main menu → Inventory → Items. Use the controls above the list to narrow it:

  • Search by item name, code, tag or lot number.
  • Filter by Status: All, Reorder now, Reorder soon, Adequate or Building data.
  • Filter by Location: where the stock is stored.
  • Filter by Tags: pick one or more tags. Each chosen tag appears under the filters with an ×, and Clear tags removes them all.
  • Show deactivated adds items that have been deactivated.

Figure 1. The Items board filtered to the tag Central laboratory, with the action buttons above the list and each item's code and tags under its name.

Read each row as follows:

  • On hand: the quantity in stock, in the item's units.
  • Usage trend and Runs out: projected from recorded use. Until enough use has been recorded, Runs out reads Too few days of use to project a run-out date, or Out of stock when nothing is left.
  • Order by: the date to place an order, with the lead time underneath, for example 30d (set) when a lead time was entered on the item, or 30d with a note to set it when none was entered and the default is used.
  • Status: Reorder now, Reorder soon, Adequate or Building data (not enough history yet). On order is added once the item has been marked as ordered.
  • Last count: the date of the last physical count, or Never counted.

Step 2: Check an item's lots

Press the arrow at the start of a row. The expanded row lists the item's lots with Lot Number, Expiration Date, Current Quantity, Status, QC Status, Storage Location and Flag. The lot to use next is flagged Use first. Under the lots, the row shows the median daily use over the last 30 days and the quantity by location.

Figure 2. Xpert MTB/RIF Ultra cartridge expanded: one active lot with QC Passed, not yet assigned to a storage location and flagged Use first.

The menu at the end of a lot row has Edit lot and location, Adjust Quantity, Update QC Status and Dispose Lot.

Figure 3. The lot menu: Edit lot and location, Adjust Quantity, Update QC Status and Dispose Lot.

Step 3: Correct a lot's details

Open the lot's menu and choose Edit lot and location. Edit Inventory Lot shows the catalog item and initial quantity, which cannot be changed here. Correct the Lot Number, Expiration Date or Receipt Date, assign a storage location with Assign storage location, and set the QC Status or Status if needed. The lot's barcode is locked once saved so printed labels keep working. Press Save.

{{IMG:g04-edit-lot.png}}

Figure 4. Edit Inventory Lot for Ziehl-Neelsen stain kit lot HC468123 with an Expiration Date entered; the catalog item and initial quantity are greyed out and QC Status is still Pending.

Step 4: Record a lot's QC result

New lots arrive with QC Status Pending, and lots stay unusable for testing until QC is marked Passed. When the lot has been checked, open its menu and choose Update QC Status. Choose the New QC Status (Pending, Passed, Failed or Quarantined), add Notes on the check you did, and press Update.

{{IMG:g05-update-qc-status.png}}

Figure 5. Update QC Status for lot HC468123 of Ziehl-Neelsen stain kit: current status Pending, new status Passed, with a note on the control slides.

The lot row then shows QC Passed, and the lot to draw next is flagged Use first.

{{IMG:g06-lot-qc-passed.png}}

Figure 6. Ziehl-Neelsen stain kit after the update: lot HC468123, 6 kits, QC Passed and flagged Use first.

Step 5: Act on an item

The menu at the end of an item row has Receive stock, Record Usage, Edit item details and Deactivate item.

Figure 7. The item menu for Bioline Malaria Ag P.f/Pan rapid test: Receive stock, Record Usage, Edit item details and Deactivate item.

Step 6: Receive stock for one item

To add stock of a single item, choose Receive stock on its row menu. Receive stock opens with the item already chosen in Item Name; you can also scan or type its UPC under Scan a product barcode. Enter the Quantity received (in the item's units), the Lot Number (leave it blank to have one generated from the item code and today's date) and the Expiration Date, and press Receive. For a delivery of several items, use the Receive page instead (see Receive stock and run inventory reports).

{{IMG:g02-receive-from-row.png}}

Figure 8. Receive stock opened from the Giemsa stain solution row: 3 bottles of lot GS2610A with an expiration date.

The new lot appears under the item with QC Status Pending until its QC is recorded (Step 4).

{{IMG:g03-received-lot-pending-qc.png}}

Figure 9. Giemsa stain solution after receiving: lot GS2610A, 3 bottles, QC Pending, no storage location assigned yet.

Step 7: Define a new item

Press New item. The dialog notes This defines a kind of item. To add more of one that already exists, use Receive stock. Enter the Item Name and, as needed:

  • Code: leave blank to have one generated from the name.
  • Tags: type to find a tag or add a new one. An item can carry more than one.
  • Category, Manufacturer, Catalog number and Product barcode (UPC or GTIN), the barcode that is the same on every box of the product.
  • Units, for example mL, tests or kits.
  • Track lots and expiry: turn on for anything received in batches with an expiry date; leave off for consumables counted as a single pool.
  • Low Stock Threshold, Lead time (days) (leave blank to have it learned from your deliveries), Warn this many days before expiry, Stability After Opening (days), Storage Requirements, Compatible Analysers and Tests Per Kit.

Press Save.

Figure 10. New item filled in for Sodium hypochlorite 5% solution: category Disinfectants, manufacturer Jik, units litres, lots not tracked.

Step 8: Review reorder suggestions

Press Reorder suggestions (the number in brackets is how many items it lists), or Review and mark as ordered in the banner. The dialog lists items at or below their threshold, or projected to reach it before a new order could arrive, with On hand, Low Stock Threshold, Order by and Status. Export CSV downloads the list.

Figure 11. Reorder suggestions: items below their threshold, two of them already On order, with the Note and Expected date fields and Export CSV.

Step 9: Mark items as ordered

In Reorder suggestions, tick the items you have ordered. Add a Note, for example the requisition or purchase order reference, and the Expected date of delivery. The bar above the list counts the items selected; press Mark as ordered. As the dialog says, this records that an order was placed; it does not place one. The same bar has Not ordered after all, Export CSV and Cancel.

{{IMG:g07-mark-as-ordered.png}}

Figure 12. Microscope slides, frosted end ticked in Reorder suggestions, with the note Requisition CPHL-REQ-2026-0412 and the expected date 2026-11-05.

On the board the item now shows On order beside its reorder status.

{{IMG:g08-marked-on-order.png}}

Figure 13. The Items board after marking: Microscope slides, frosted end shows Reorder now and On order.

Step 10: Count stock

Press Count mode. Each lot-tracked row gets a count box showing the quantity on hand (of 340 tests); items with nothing in stock read Nothing here to count. A banner explains Counting everywhere. Filter by location to count one shelf at a time. Only what you type is committed. Type the quantity you count. The difference from the recorded quantity appears beside it, and the banner counts the lots you have entered. Press Cancel to leave count mode without changes.

Figure 14. Count mode: 338 typed for Determine HIV-1/2 rapid test against 340 on record, shown as -2, and the banner reading 1 lot counted.

Step 11: Confirm the count

Press Confirm count. Only the counts you typed are committed. A message summarises what was recorded, for example Count recorded: 1 correction, none confirmed. The item's On hand changes to the counted quantity and Last count shows today's date.

{{IMG:g09-count-confirmed.png}}

Figure 15. After Confirm count: the message Count recorded: 1 correction, none confirmed, and Determine HIV-1/2 rapid test at 338 tests, last counted Oct 22.

Step 12: Import items from a file

Press Import items. The dialog explains that a CSV file can define many items at once, that the preview saves nothing, and that re-importing a corrected file updates the same items rather than adding them again. Use Download the template for the column layout, then Add a CSV file and press Preview. What this file would do counts the lines that are new, updated, unchanged and skipped, and lists each line with its outcome and, for a skipped line, the reason.

Figure 16. The import preview for lab-consumables.csv: one new item and one unchanged item, nothing skipped.

Step 13: Apply the import

When the preview is right, press Apply. The heading changes to What was imported, with the same counts and lines. Press Close to return to the board, where the new items appear. A new item with nothing in stock is listed under Reorder now straight away.

{{IMG:g10-import-applied.png}}

Figure 17. The import applied: 2 new items, Giemsa stain solution and Sodium hypochlorite 5% solution, nothing updated or skipped.

Step 14: Record usage

Press Log usage (or Record Usage on an item's menu). Choose the Item Name and enter the Quantity used. The dialog shows how much is on hand and that lots are drawn earliest-expiry first. Press Record Usage. Recorded use feeds the run-out projection; to correct a count, use Adjust Quantity on the lot instead.

Figure 18. Log usage for Determine HIV-1/2 rapid test: 20 tests used, with 340 tests on hand.

Step 15: Manage tags

Press Manage tags. The dialog lists every tag with the number of Items carrying it and its Status. To add a tag, type it in New tag and press Add tag; you can then pick it on items. Deactivate stops a tag being suggested or offered as a filter; items already carrying it keep it. Tick Show deactivated to list deactivated tags as well.

{{IMG:g01-manage-tags.png}}

Figure 19. Manage tags after adding Haematology: each tag with its item count, Active status and Deactivate.

Step 16: Follow up low-stock alerts

Items that need reordering also raise Low stock alerts. Go to Main menu → Alerts and set Alert Type to Low stock. Each alert reads <item> needs reordering now, with its Severity, Status and Created time. Press Acknowledge to show the alert has been seen. An alert for an item that has been restocked shows Resolved.

{{IMG:g11-alerts-low-stock.png}}

Figure 20. Alerts filtered to Low stock: Open alerts for items that need reordering, each with Acknowledge, and the alert for Ziehl-Neelsen stain kit, restocked since, shown as Resolved.

Tips

  • Enter a lead time on each item. Until you do, Order by uses a default of 30 days and says so.
  • Tag items by section (for example TB laboratory) and by kind (for example Rapid tests). The tag filter, the reports and the import file all use the same tags.
  • Deactivate tags you no longer use, for example near-duplicates. A deactivated tag is no longer suggested or offered as a filter; items that carry it keep it.
  • Count one shelf at a time by filtering by location before you press Count mode.
  • Usage is drawn from lots whose QC has passed. When the only lots of an item are still awaiting QC, recording usage was refused on the test server; set the lot's QC status first with Update QC Status.
  • Known issue (OGC-1549): the Reorder now banner and the Reorder suggestions list ignore the tag filter, so they also list items outside the tags you picked (Figures 7 and 11).
  • The figures were captured with British English labels (for example Compatible Analysers). Your screens may use American spelling.
