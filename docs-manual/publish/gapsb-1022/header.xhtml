Overview

The header of the redesigned patient report takes the laboratory name from the SiteName setting and the logo from the headerLeftImage setting on Printed Report Configuration. Until they are set, reports print without a laboratory name or logo. Printed Report Configuration is a table of named settings, each with a Description and its current Value; you change one at a time with Modify.

Step 1: Open Printed Report Configuration

Go to Main menu → Admin → General Configurations → Printed Report Configuration. The list shows each setting's Name, Description and Value.

{{IMG:r01-printed-report-config-before.png}}

Figure 1. Printed Report Configuration before any change: ten settings, with only reportPageNumbers (false) and reportPaperSize (A4) holding a value.

Step 2: Set the laboratory name

Select the SiteName row and press Modify. In Edit Record, type the laboratory name in Value and press Save (Exit leaves without saving).

{{IMG:r02-edit-site-name.png}}

Figure 2. Edit Record for SiteName with the value Port Moresby General Hospital Laboratory.

Step 3: Upload the logo

Select the headerLeftImage row and press Modify. Press Choose file and pick the logo; the screen accepts JPG, PNG or GIF files up to 2 MB and shows a preview. Press Save. To take a logo off later, tick Remove Image and save.

{{IMG:r03-edit-header-left-image.png}}

Figure 3. Edit Record for headerLeftImage with a laboratory logo chosen and previewed, and the Remove Image option.

Step 4: Check the settings

Back on the list, the SiteName row shows the name and the headerLeftImage row shows the logo.

{{IMG:r04-printed-report-config-after.png}}

Figure 4. Printed Report Configuration after the change: SiteName Port Moresby General Hospital Laboratory and the logo in headerLeftImage.

Step 5: Print a report to check the header

Print a patient report from Main menu → Reports → Routine → Report Print Queue (see Report Print Queue: print and reprint patient reports). The logo prints on the left and the laboratory name above the report title.

{{IMG:r05-report-header-printed.png}}

Figure 5. The top of a partial report printed after the change, for DEV01260000000001254: the logo and Port Moresby General Hospital Laboratory above Results: partial report.

Field reference

SettingDescription on screen
SiteNameThe name of the site for reports and header. Printed as the laboratory name in the report header.
headerLeftImageImage for the left side of report header (JPG, PNG or GIF, up to 2 MB). Printed as the logo.
headerRightImageImage for the right side of report header.
additional site infoAdditional information for report header.
lab directorThe lab directors name for the reports.
labDirectorName, labDirectorTitle, labDirectorSignatureImages for the lab director's name, title and signature.
reportPageNumbersUse page numbers on reports (false on the test server).
reportPaperSizePaper size of printed reports (A4 on the test server).

Tips

  • Use a square logo with a plain background; it is printed small beside the laboratory name.
  • Set the header before you start printing reports for clinicians. A reprint gives the version already issued: on the test server a reprint was labelled Reprinted version 1 and kept the original Issued time at the foot of the report.
  • Patient ID and URAP Number on the report printed blank for a patient whose record held only a National ID. After a Patient ID was added to the patient, the reprint of version 1 still showed Patient ID blank. Whether a new version picks it up was not checked.
  • Program printed blank on the test order although the order had the program Routine Testing in Modify Order.

Not yet available
