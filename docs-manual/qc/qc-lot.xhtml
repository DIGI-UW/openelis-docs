How-to · Quality officers and bench supervisors

Status: draft for review. Driven on pngtest.openelis-global.org, version 3.2.2.0, 27 September 2026. Replaces the unpublished 3 September draft, which described an earlier form. See Provenance.

At a glance

PurposeRegister a new lot of control material so its results can be judged against the lot's target mean and standard deviation.
You'll end up withAn Active control lot in the Control Lots list, tied to one test and either an analyzer or the bench, with its statistics method set.
Who does thisThe person who puts new control material into service, typically a quality officer or bench supervisor. Access is set by user permissions and can be configured by your administrator.
Before you startThe control material in hand, with its lot number, level, expiry date and, for a fixed target, the manufacturer's mean and standard deviation from the package insert.
WhereMain menu → Quality Assurance → Statistical QC → QC Lot Management.

Step 1 — Start a new lot

Open QC Lot Management and click New Control Lot. The New Control Lot form opens.

Step 2 — Describe the lot

  1. Enter the Lot Number and the Control Material name as printed on the vial.
  2. Choose the Control Level: Low, Normal or High.
  3. Enter the Expiration Date.
  4. Choose the Analyzer the lot is run on, or Bench / no analyzer (manual method) for a control run at the bench without an instrument. The help text under the field says the analyzer is optional.
  5. Choose the Test the control is for. The list shows each test with its sample type.
  6. Leave Status switched to Active to put the lot into service now.

{{IMG:01-new-lot-filled.png}}

Figure 1. A new lot for a Normal haemoglobin control run at the bench.

Step 3 — Set the statistics method

  1. In Statistics Configuration, click Configure.
  2. Choose the Calculation Method:
    • Manufacturer Fixed — use the manufacturer's mean and SD.
    • Rolling Window — recalculate from the most recent N results.
    • Initial Runs — calculate once from the first N establishment runs.
  3. For Manufacturer Fixed, enter the Mean and Standard Deviation under Manufacturer Values, then click Save in the dialog.

{{IMG:03-configure-filled.png}}

Figure 2. The Statistics Configuration dialog with Manufacturer Fixed chosen, mean 13.2 and SD 0.4.

The values appear in the Statistics Configuration block on the form.

{{IMG:04-lot-with-stats.png}}

Figure 3. The form with the statistics filled in, ready to save.

Rolling Window and Initial Runs were not driven; the fields they show have not been verified on a live instance. Confirm before publishing.

Step 4 — Save

Click Save. The Control Lots list opens with the new lot shown as Active.

{{IMG:06-lots-list.png}}

Figure 4. The new lot in the Control Lots list.

Field reference

FieldNotes
Lot NumberThe lot number printed on the control material.
Control MaterialThe product name.
Control LevelLow, Normal or High. The list shows it in capitals (for example NORMAL).
Expiration DateThe lot's expiry date.
AnalyzerOptional. An analyzer, or Bench / no analyzer (manual method).
TestThe test the control is for.
StatusActive or inactive. The list can be filtered by status.
Calculation MethodManufacturer Fixed, Rolling Window or Initial Runs, set with Configure.
Mean / Standard DeviationThe target values used with Manufacturer Fixed.

Tips

  • The Control Lots list has a Manufacturer column, but the form has no Manufacturer field, so the column shows a dash for lots created here.
  • Saving a bench lot does not add anything to Rule Configuration: after saving the lot above, Rule Configuration still showed "No rule configurations found." Whether an analyzer lot creates a rule set was not tested, because pngtest has no analyzers.
  • The breadcrumb reads Analyzers › Quality Control Dashboard › Control Lots even when you arrive from Quality Assurance. This is a known inconsistency and does not mean you are on a different page.

Not yet documented

  • Editing, deactivating or retiring a lot (the row options menu was not opened).
  • Lots tied to an analyzer.
