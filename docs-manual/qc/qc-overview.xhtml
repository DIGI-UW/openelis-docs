At a glance

PurposeKnow where statistical quality control lives in OpenELIS and check each day whether any control has failed.
You'll end up withA view of instrument QC status, bench and rapid-test controls, and any violations that need action.
Who does thisQuality officers and supervisors, and bench staff who run controls. Access is set by user permissions and can be configured by your administrator.
Before you startAt least one active control lot (see Receive and activate a control lot).

Check QC status each day

  1. Open QC Dashboard. The four tiles at the top show Instruments In Control, Warning Status, Out of Control and Overall QC Pass Rate. Last Updated shows when the figures were read; Refresh and Export sit beside it.
  2. The Instruments tab lists each instrument with its Type, Location, Status, Analytes, Recent Violations, Last Update and Actions. Use Search instruments to find one.

{{IMG:01_qa_qc_dashboard.png}}

Figure 2. The QC Dashboard on its Instruments tab. This instance has no instruments connected, so the list is empty.

  1. Open the Bench QC tab to see controls recorded without an analyzer, such as rapid-test controls. Each row shows the Lab unit, Test, Source, Controls run, how many Failed, and when the last one was run. Filter with Source.

{{IMG:09-bench-qc.png}}

Figure 3. The Bench QC tab with one rapid-test control run for HIV Rapid Test in Serology, marked as failed.

  1. Open the Alerts tab (or QC Alerts in the menu). Active QC Violations lists violations not yet acknowledged; Acknowledged Violations lists those already dealt with. Choose the Time Period to look back over, for example Last 72 Hours.

{{IMG:11-alerts.png}}

Figure 4. The Alerts tab with no active or acknowledged violations in the last 72 hours.

Acknowledging a violation has not yet been verified on a live instance, because no violation was available to act on. Confirm before publishing.

Tips

  • A failed bench control does not appear on the Alerts tab: with the failed HIV Rapid Test control in Figure 3 on the dashboard, Alerts showed no violations. Check the Bench QC tab as well as Alerts.
  • These pages show Analyzers › Quality Control Dashboard in the breadcrumb even when reached from Quality Assurance. This is a known inconsistency, not a different page.
  • How rapid-test and manual control results are recorded is not yet documented in this manual.
